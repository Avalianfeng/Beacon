# 外部 · _共享（可复用层）

> 契约：`全流程分析/prompts/外部/说明-索取目录契约.md`  
> **这里不是「大索取锅」**。完整索取叙事在各 `V*/索取/`。

| 路径 | 放什么 |
|---|---|
| `scripts/` | 可复用算子（输入/输出写进本目录 README） |
| `切片/` | 可复用 csv/png 等；**必须**登记 `切片/_索引.md` |
| `切片/_索引.md` | 切片 ID · 文件 · 口径 · 首次产出 · 被哪些 V/轮复用 |

## 禁止

- 把某 V 的轮次原文、地图、打包成品丢进这里  
- 无索引的「先扔着」文件  
- 用本目录整夹直接 `pack_external_upload`（应 pack `V*/索取/轮N`）
