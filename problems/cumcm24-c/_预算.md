# cumcm24-c · 探索预算（最小）

| 线 | 预算提示 |
|---|---|
| 外部对撞 | **每个 V** 最多 2 轮 A 索取；第 2 轮收口；Diff 前尽量 ≥2 闭环视角 |
| 共享切片 | 先查 `_共享/切片/_索引.md`；同口径只记账复用，不复制第二套 |
| 本地地图 | V1 开跑一轮后再派；一次长探索；可读 `_共享/切片`，禁读各 V 索取/地图/轮次/外发 |
| 禁止 | 搜本题题解；pack `_共享` 整夹；把 V1 索取叙事喂给 V2/本地 |

成本以人盯对话轮次与本机算力为准；超预算先停、问人。

python scripts/scaffold_external_maps.py --problem problems/cumcm24-c
