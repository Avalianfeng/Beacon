## formula_notes

- 星期 WD=0..6（一…日）。2023-07-01 WD=5。  
- WD90(c,t) = 截止日前 90 日内、同 WD 的品类净销量均值。  
- WIN7(c) = 2023-06-24..30 品类日均（目标周）；回测中为 t 前 7 日均。  
- MU90(c) = 近 90 日品类日均。  
- **d̂(c,t) = WD90(c,t) × WIN7(c) / MU90(c)**。  
- λ_c 品类损耗（花菜 0.1551，水生 0.1365，花叶 0.1283，菌 0.0945，椒 0.0924，茄 0.0668）。  
- q(c,t) = d̂(c,t) / (1−λ_c)。  
- ĉ_c = 窗内 Σ(销量×批发) / Σ销量。  
- m_c = 近90 非打折行 (单价/批发−1) 的 P50。  
- p_c = ĉ_c × (1+m_c)。一周不变。  
- π = Σ [ p·d̂ − ĉ·q ]（点预测、卖完代理需求）。粘性售价冲击：p 不变、c←ĉ(1+δ)。  
- Q3：d_i = d̂(c(i), 7/1) × (net_i / Σ_{hard∩c} net)；q_i = max(2.5, d_i/(1−λ_i))；π_i = p_i min(d_i,(1−λ_i)q_i) − c_i q_i。  
- 单位可售毛利 = p − c/(1−λ)；≤0 则不上架。
