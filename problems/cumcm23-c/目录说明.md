# 题目录结构（cumcm23-c）

```text
problems/<题>/
  problem.md / problem.json / data_profile.md   ← CLI/stage 要求留在题根（勿迁 source）
  exploration.md                               ← 收束时人读产物（配合 brief；非对撞地图）
  本地资产清单.md / 目录说明.md                   ← 主持索引（题根）
  _派发/                                       ← 全部可粘贴派发（本地/diff/研究）
  eda/                                         ← S1 概览图
  source/                                      ← 附件 + 方向生产填充件
  认知地图集/
    外部/{地图,轮次,外发归档,索取}/
    本地/Vn/
    diff/
    清点/                                      ← 拍板 / 主线 / 逐问 / 领域知识
  （研究外显，题根）_研究日志.md 解题说明.md 经验与坑.md brief草稿.md
```

已废止：题根 `索取/`、`对撞外部/`、`求解/`、题根 `清点/`、各站散落的 `派发.md`。

**CLI 例外**：`problem.md` / `problem.json` / `data_profile.md` 留题根，迁走会破坏 `stage` / `--problem`。

**用法**：定稿 `全流程分析/全流程定稿/`。派发一律 `_派发/`。研究工作区=题根。
