# C题 · 可执行认知地图（定稿前探索版）

> **定位**：本轮只把探索收成可供主持方 diff / 清点的地图；不进入求解代码，不给最终模型公式全集。
> **主骨架固定为：**
> **观测销量 ← 潜在需求 / 可售状态 / 价格 / 促销打折 → 品类级预测 | SKU级预测 → 损耗、空间约束 → 补货 + 定价 + SKU组合 → 收益；凌晨不知进货价 = 信息不完全。**

------

## 0. 总体地图：问题不是“预测销量”，而是从观测反推决策

1. **必做｜观测层**：附件2直接给的是实际销售流水，不是真实潜在需求；零销量同时可能来自低需求与不可售。
2. **必做｜驱动层**：时间/季节、星期、价格、打折、SKU/品类结构共同作用于观测销量。
3. **必做｜预测层**：Q2先形成品类级需求判断，Q3再下沉到SKU级；两层共享历史结构，但不应强行共用同一尺度。
4. **必做｜决策层**：预测结果经过损耗、有限空间、最小陈列量、未来成本不确定性后，才转成订货与定价。
5. **必做｜目标层**：最终不是“预测最准确”，而是使补货、定价、SKU组合在题面条件下产生最大合理收益。
6. **应做｜解释层**：每个关键参数都应保留“事实 / 【推断】 / 不可识别”三种状态，避免把缺失信息伪装成已知。

------

# 1. Q1：销售分布规律——先描述“观测世界”，再谈潜在需求

1. **交付物｜必做**：给出6品类及SKU销售量级、离散程度、尾部、零值、季节/星期变化和品类间关系。
2. **结构｜必做**：品类规模极不均衡：251个SKU中花叶100、食用菌72、辣椒45，而花菜仅5；因此不能把SKU数量当需求权重。
3. **结构｜必做**：全店观测日量存在明显尖峰；花叶日销量P50=172.1 kg、P95=321.4 kg、最大1265.5 kg，峰值远高于典型日。
4. **机制｜必做**：月份差异不仅是季节效应，还混入阶段变化与星期结构；2023-04～06中六品类均有周末放大。
5. **机制｜必做**：花叶周六/周日约为同期总体的1.29/1.25倍，辣椒周六1.41倍，食用菌周六1.47倍；星期效应不能被忽略。
6. **口径歧义｜必做**：日历补0适合描述“实际经营结果”，但不能直接等价于“有货条件下市场需求”。

### 方法族：Q1

- **主线｜必做**：分层的时间—品类—SKU探索；先描述分布，再分析控制时间结构后的关联。
- **对照A｜应做**：无时间控制的相关/聚类，只作为“发现关系”的基线。
- **对照B｜应做**：去除星期或分季节后的关联稳定性检查；若主线与对照差异大，说明原相关可能由共同时间驱动。
- **不兼容**：不能同时把“简单相关=商品因果关联”和“控制共同时间后仍有稳定关系”都作为同一主结论。

------

# 2. Q1 的品类/SKU关联：必须防止“共同驱动”伪装成关联

1. **必做｜机制**：两个SKU共同在周末上涨，不足以证明互相替代或互补；共同季节因素也会制造正相关。
2. **必做｜淘汰**：品类行级量价相关不能直接当需求弹性；食用菌某些月份可达约−0.98，而同SKU日级中位仅约−0.02，差异过大。
3. **必做｜淘汰依据**：同SKU Pearson中位大致落在0～−0.2附近，说明“食用菌行级−0.98=品类价格弹性”应明确淘汰。
4. **应做｜结构**：SKU关系应区分“同类共同波动”“潜在替代”“潜在互补”三个概念，当前数据最多可靠支持第一层探索。
5. **存疑｜机制**：供应来源编号可能反映价格/质量/渠道差异，但不能仅凭名称中的(1)(2)(3)推断供应商行为。

### 方法族：Q1关联

- **主线｜必做**：分层/控制时间后的相关结构。
- **对照A｜应做**：原始相关矩阵，展示“未控制时看起来多强”。
- **对照B｜应做**：按品类聚合后的相关，观察品类层与SKU层是否一致。
- **不兼容**：若最终选择控制后的关系作为主线，就不能同时把未控制相关作为机制性结论。

------

# 3. Q2：需求预测——历史不是一条平稳线

1. **必做｜结构**：2023-06花叶日均155.3 kg，而2023-01为243.9 kg；三年长期均值明显不能直接当7月需求。
2. **必做｜结构**：窗口7天又进一步降到花叶124.8 kg/d、辣椒77.6 kg/d、食用菌44.2 kg/d，近期状态不能忽略。
3. **必做｜异质性**：窗口/近30日中位约为花叶0.94、花菜1.00、水生1.04、茄0.69、辣椒0.85、食用菌0.87，品类近期变化方向并不统一。
4. **必做｜淘汰**：窗口下滑不能一句概括成“季节性变弱”；花叶有32%的六月有售SKU窗口掉出，而茄/辣椒为0%，留存SKU自身状态也在变化。
5. **应做｜星期**：周末放大是近期数据中的稳定结构，7/1～7本身跨周末，日补货不应只给一个品类常数。
6. **存疑｜节假日**：4–6月星期效应混入清明、劳动节、端午，不能直接把该系数无条件外推到整个7月。

### 方法族：Q2需求预测

- **主线｜必做**：分解型时间需求基线（近期状态 + 季节/日期结构 + 星期效应）。
- **对照A｜应做**：纯近期基线，如近30日/近7日修正，用于检验复杂结构是否真正改善。
- **对照B｜应做**：季节基线，如历史同月/同周历比较。
- **不兼容**：不能把“近30日直接外推”和“完整时间分解预测”同时作为主模型，只能作为对照。

------

# 4. Q2：成本与定价——“成本加成”不是固定加成率

1. **必做｜结构**：批发价跨品类、跨时期剧烈变化；已售批发价P50从花叶3.60到水生7.00，极端可达141。
2. **必做｜淘汰**：不能把全体批发价直接作为同尺度成本分布；141对应拼装礼盒，0.01也存在于不同SKU。
3. **必做｜机制**：不同包装/规格/供应来源可能混入同一“元/kg”字段，先统一使用成本分布会扭曲成本加成关系。
4. **必做｜信息不完全**：7/1凌晨不知道真实进货价，因此未来成本应视作决策时的未知量，而不是已知参数。
5. **应做｜近期稳定性**：49个窗口SKU的周内CV中位数从食用菌0.005到辣椒0.076，说明近期成本可预测程度存在品类差异。
6. **存疑｜价格机制**：同SKU近期价格响应普遍弱，不能默认所有SKU都存在可识别的价格弹性。

### 方法族：Q2定价

- **主线｜必做**：成本条件下的价格—需求决策，同时显式区分未来成本未知。
- **对照A｜应做**：成本加固定加成的经营规则，作为题面“成本加成定价”的直观基线。
- **对照B｜应做**：价格敏感性较弱的需求响应基线，用来检验定价优化是否真的比规则法有效。
- **不兼容**：不能同时声称“真实价格弹性强、可以精细优化”和“同SKU普遍无显著价格响应”而不区分证据层级。

------

# 5. Q2：价格—销量关系——当前最应该“降格使用”的变量

1. **必做｜事实**：同SKU、按日聚合后的Pearson中位数只有弱负区间：花叶−0.191、辣椒−0.155、食用菌−0.024。
2. **必做｜淘汰**：食用菌行级相关约−0.76甚至−0.98，不能直接视为品类价格弹性。
3. **必做｜机制**：同SKU也未控制季节、星期、打折，所以弱相关不能证明“价格没作用”。
4. **应做｜定价角色**：价格响应目前更适合作为“候选机制”，而不是Q2全部预测能力的主来源。
5. **存疑｜SKU异质性**：小皱皮(份)−0.575、洪湖藕带−0.491等个别SKU有明显负向信号，可能存在局部价格响应。
6. **口径**：同SKU量价检验用的是有正销售的日均价与日销量，不能把它直接和全流水相关混为一谈。

### 方法族：价格响应

- **主线｜必做**：把价格作为辅助需求驱动，并进行稳健性检验。
- **对照A｜应做**：不加入价格响应，只用时间/历史状态预测需求。
- **对照B｜应做**：仅对存在较稳定负向信号的SKU使用价格响应。
- **不兼容**：不能把“所有SKU统一价格弹性”作为主线；当前证据不支持。

------

# 6. Q3：49个SKU不是“可售事实”，而是近期候选集合

1. **必做｜事实**：2023-06-24～30窗口共有49个出现销售的SKU，全部窗口内出现过的SKU均有当天批发价匹配。
2. **必做｜边界**：49来自“窗口内出现过销售”，并不等于“7/1一定可以进货”。
3. **必做｜淘汰依据**：因此不能把49写成7/1确定可供全集，只能写成近期观察到的候选集合。
4. **必做｜结构**：49个候选按品类为17/2/7/5/10/8（花叶/花菜/水生/茄/辣椒/食用菌），本身就存在严重不均衡。
5. **应做｜SKU筛选**：49→27–33是组合选择问题，不是单纯需求排序。
6. **存疑｜供给机制**：没有库存、订货上限、供应商可供量，因此最终只能把“候选集合”而非真实供给能力纳入。

### 方法族：Q3候选集

- **主线｜必做**：以窗口49个SKU作为近期候选集，再在其中做27–33选择。
- **对照A｜应做**：以全部长期有销量SKU作为更宽候选集，验证窗口限定是否过窄。
- **对照B｜应做**：仅以窗口7天稳定销售SKU作为更保守候选集。
- **不兼容**：不能同时把三种集合都称为“题目规定的可售全集”。

------

# 7. Q3：27–33个SKU——空间本质上是稀缺资源

1. **必做｜结构**：49个候选中至少淘汰16个、最多保留33个，因此SKU选择是核心决策，不是附属步骤。
2. **必做｜约束**：每个被选SKU订购量满足至少2.5 kg，这是硬约束。
3. **必做｜机制**：一个SKU占用一个陈列名额，就形成对另一个SKU的机会成本。
4. **必做｜淘汰**：按目录SKU数量比例分配名额不合理；花叶100个SKU、花菜5个SKU不能推出同样的需求权重。
5. **必做｜目标解释**：“尽量满足各品类需求”未给固定满足率，更适合被视为软目标/判据。
6. **应做｜运营含义**：单纯按销量排序也不够，因为高销量、低损耗、高单位利润、品类覆盖价值可能互相冲突。

### 方法族：Q3组合

- **主线｜必做**：需求覆盖 + 单品经济贡献 + 空间名额的组合选择。
- **对照A｜应做**：单纯按预测需求排序选27–33个SKU。
- **对照B｜应做**：按单位空间贡献/单位利润排序。
- **不兼容**：不能把“需求最大化”和“利润最大化”两个排序规则同时作为主线。

------

# 8. 损耗：两个表不是同一个统计量

1. **必做｜事实**：品类损耗率与单品损耗率分布不同；例如花菜品类平均15.51%，但单品P50=9.43%。
2. **必做｜事实**：茄类单品P50=6.94%，接近其品类平均6.68%，说明9.43%不是所有品类的共同中心。
3. **必做｜警报**：251个SKU中22个为0%，85个恰为9.43%，约占33.9%；9.43存在明显集中。
4. **必做｜边界**：附件4没有盘点起止日期，因此不能严格证明其损耗率对应2023-07-01状态。
5. **应做｜层级**：Q2更接近品类层决策，Q3更需要SKU层差异；但这是【推断】，不是题面硬规定。
6. **存疑｜可信度**：9.43%的重复值究竟是真实共同估计值、填补值还是盘点口径结果，现有数据不能证实。

### 方法族：损耗

- **主线｜必做**：按决策层级使用对应损耗口径，并对9.43集中值做敏感性。
- **对照A｜应做**：统一品类损耗率。
- **对照B｜应做**：统一9.43%作为简化基线。
- **不兼容**：不能同时把“单品损耗是真实异质参数”和“所有SKU统一9.43%”作为主解释。

------

# 9. 收益函数：整题目前最大的语义闭合点

1. **必做｜问题**：题面给了“收益最大”，但没有库存、剩余品残值、缺货损失、进货上限、盘点起止日。
2. **必做｜边界**：若把订货量直接等价成销售量，则损耗附件失去经济作用；若不区分订货量与销售量，收益也可能不闭合。
3. **必做｜结构**：至少应区分“订货 → 损耗/有效可售量 → 销售 → 收益”的逻辑链。
4. **必做｜推断**：由于缺少剩余品与缺货经济信息，需要选一个透明的简化收益口径，并明确它是【推断】。
5. **应做｜有界性**：最终目标必须避免出现“理论上无限多订货也无限增益”的不合理解。
6. **存疑｜运营损失**：未观测的缺货损失和滞销残值不能凭空赋固定金额，只能作为敏感性或讨论项。

### 方法族：收益闭合

- **主线｜必做**：在题面数据可识别范围内构造有界、透明的经营收益口径。
- **对照A｜应做**：忽略残余价值的简化收益。
- **对照B｜应做**：引入需求未满足/损耗后的惩罚项进行敏感性分析。
- **不兼容**：不能把未知的缺货损失、残值当成精确观测参数同时写成主模型事实。

------

# 10. 五个“最危险遗漏”转成可执行口径

## 10.1 销量 ≠ 需求

- **主线如何处理**：把实际销售作为潜在需求代理，不宣称完全识别真实需求；零销量视为“需求低/不可售”混合结果。
- **论文如何交代**：明确说明缺少库存/上架状态，因而不能严格识别潜在需求；预测的是“可观测销售需求代理”。
- **什么会打脸**：若后续按SKU获得库存/缺货代理后，加入可售状态显著提高预测并改变订货排序，则当前代理假设应降级。

## 10.2 行级相关 ≠ 价格弹性

- **主线如何处理**：不采用品类行级Pearson作为弹性；价格仅作为待验证的需求驱动。
- **论文如何交代**：食用菌行级相关最高约−0.98，而同SKU中位约−0.02，说明规格混杂影响显著。
- **什么会打脸**：若控制时间、打折、SKU后仍稳定得到显著且经济意义合理的负价格响应，则可以提高价格机制权重。

## 10.3 49 ≠ 7/1全部可选SKU

- **主线如何处理**：49定义为近期观察候选集，而非确定供应全集。
- **论文如何交代**：题面只给“6/24–30可售品种”的操作语境，现有数据只能证明窗口内出现过销售。
- **什么会打脸**：若后续真实7/1采购记录显示49中大量SKU不可进货，或窗口外SKU大量可供，则49候选定义需调整。

## 10.4 9.43% ≠ 全体真实损耗率

- **主线如何处理**：保留单品差异，并把9.43高频值作为敏感性对象。
- **论文如何交代**：85/251个SKU恰为9.43%，且附件4缺少盘点时间，因此不将其解释为统一真实物理损耗。
- **什么会打脸**：若后续盘点明细证明85个SKU确实在同一时期独立测得9.43%，则可提高其可信度。

## 10.5 收益最大目前并未自动闭合

- **主线如何处理**：使用透明、有界、只依赖现有数据的收益代理，并把未知残值/缺货损失列入假设。
- **论文如何交代**：说明缺失库存、剩余价值、进货上限等数据，故收益是题面条件下的决策近似。
- **什么会打脸**：若后续计算发现优化结果对收益口径极端敏感，甚至排序反转，则应升级为多情景/稳健决策，而不能保留单一结果。

# 13. 如果最后论文只能留下5–8个探索点，必须写什么

### **必须写 1：需求非平稳**

2023-06与2023-01、近365存在显著差异，证明“三年平均直接外推”不可靠。

### **必须写 2：星期效应**

周末相对总体最高达到食用菌1.47、辣椒1.41、花叶1.29，直接解释为什么Q2应考虑逐日补货。

### **必须写 3：Q3的SKU结构变化**

花叶六月有售SKU中32%在窗口掉出，而茄/辣椒为0%；说明近期变化既有品类状态变化，也有SKU组合变化。

### **必须写 4：行级量价相关被SKU层对撞削弱**

食用菌行级相关可到约−0.98，但同SKU中位约−0.02；这是非常有说服力的方法淘汰证据。

### **必须写 5：成本存在异质性与信息不完全**

49个窗口SKU成本CV从很低到辣椒约7.6%中位不等，且7/1真实进货价未知。

### **必须写 6：损耗双口径与9.43集中**

85个SKU恰为9.43%，同时品类平均与单品中位可能明显不同；不能无条件统一。

### **必须写 7：空间使Q3成为组合决策**

49→27–33且每SKU≥2.5 kg，说明“选什么”与“订多少”同等重要。

### **应写 8：收益函数的不可识别边界**

没有库存、残值、进货上限、缺货损失，因此收益模型中的相关处理必须明确标【推断】并接受敏感性检验。
