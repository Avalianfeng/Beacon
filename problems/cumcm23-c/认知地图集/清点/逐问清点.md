## 逐问展开（选定方向 / 禁止 / 口径）

### Q1

**选定**

- 交：各品类（及必要单品）销量分布（分位、零销、季节/星期）；品类间相关的两层图——原始相关与去季节（月份）残差相关；说明共同时间驱动 vs 结构共变。  
- 单品层：长尾、可替换性/供应源编号提示；退货可忽略量级。  
- 明确：**行级/月切片强负相关 ≠ 价格弹性**（同 SKU 日级仅弱负为主）。

**禁止 / 降级**

- 禁止把茄类「低原始相关」写成七月「结构独立」主结论（拍板 6=B；Diff V7）。  
- 禁止用关联规则冒充因果互补/替代定论。

**口径**

- 净销量 = 销售流水合计（退货为负行）；分析用日历补 0 或有售日须各自声明②。  
- 需求不可识别：本文销量是实现销量①+②。

### Q2

**选定**

- 需求主锚：近 90 同星期 × 近窗水位；共同日期/周末因子进入逐日；2022 同周仅压力（拍板 2=A, 7=A, 6=B）。  
- 成本：近窗批发价中心 + ±10/20% 情景（进价 7/1 凌晨未知①）。  
- 定价：历史非打折加成带内选点；少数证据稳定 SKU 可试价格响应作对照（拍板 3=A+B）。  
- 损耗：品类表；9.43 重复值敏感性（拍板 4=A）。  
- 收益：未售按进货成本全损，销量 ≤ (1−λ)×订货；标【推断】②（拍板 5=A）。  
- 交付：2023-07-01–07 各品类日补货总量 + 定价（可给加成或标价其一，须自洽）。

**禁止 / 降级**

- 禁止三年总均值当 7 月水位。  
- 禁止品类统一弹性最优作为主定价（C 仅对照）。  
- 禁止「订得越多收益越高」无上界会计。

**口径**

- 目标周星期序：六、日、一、二、三、四、五①（日历事实）。  
- 品类日销量口径与 Q1 声明一致。

### Q3

**选定**

- 可售叙事：窗内有销 49 为候选；默认硬池 29；在 27–33 内边际调整；相对日上架 35–45 为**收紧**②（拍板 1=A）。  
- 2.5 kg：订购量下界①；硬池已按窗内日均≥2.5 筛选（Diff V1）。  
- 替代组：份/散、同名不同编号默认不双占格，留硬池侧（通常份装）②。  
- 定价/收益：与 Q2 同族；损耗改用单品表 + 硬池头部 8 个恰 9.43% 与海鲜菇 0% 敏感性（拍板 4=A+C）。  
- 双目标：先保品类覆盖（硬池已六类有人），再在有界收益下微调。

**禁止 / 降级**

- 禁止默认「49 里无结构自由组合」为唯一求解叙事。  
- 有价无销 12、六月掉出 → 敏感性，不默认并入可售全集②。

**口径**

- 「可售品种」题面指向 6/24–30①；操作定义=窗内净销量>0 的 SKU②（拍板已锁）。  
- 7/1 单日；周六抬升进入单品量（拍板 7=A），但不一切 SKU 同一乘数。

### Q4

**选定（按优先级）**

1. 日进货量、期末库存/报损、售罄或缺货标记 → 把销量升级为需求/审查结构（拍板 8）。  
2. 标价与折扣分离、实际可售上下架状态 → 清洁价格识别与可售集合。  
3. 货架容量/陈列位数、供应确认（凌晨可供清单）→ 直接服务 Q3 27–33。  
4. 天气/节假日 → 辅助，不替代 1–3。

**禁止**

- 禁止只列「再采更多历史销量」而不解释对不可识别边界的帮助。
