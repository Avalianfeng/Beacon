## 二、典型模式（结构识别时对照）

1. **三段式形变**：位移-时间曲线呈"缓-加速-快"三阶段，阶段速度比典型 1:7:25（C 题官方 0.25/1.75/6.18 mm/h）；
2. **双周期/恢复期**：破坏/加速后位移回落并趋于稳定（"恢复"），随后可能再次加速——**恢复期是真实结构，不是误报**（C 题 Q5 教训 E1）；
3. **降雨滞后效应**：降雨 → 孔隙水压力上升 → 位移加速，存在数小时至数天滞后；
4. **爆破扰动**：偶发事件，爆破点距离/单段药量仅爆破时刻有值（空值语义 = 非事件，不是缺失）；
5. **微震前兆**：破坏前微震事件数增多（损伤集聚），与加速段对应；
6. **传感器特性**：振弦式（稳定、基准）、光纤式（零漂/安装偏差需校正——Q1 的 A→B 校正正是此场景）；10 分钟采集频率下跳变多为扰动/故障。

## 三、常见陷阱（对撞与评审时检查）

1. **统计异常 ≠ 领域异常**：MAD/IQR 抓到的是统计离群（含天气/趋势变化），故障跳变才是"要预警的异常"——先定义操作语义再定阈（C 题 E4：1123 vs 官方 93）；
2. **Δy 建模不声明初值**：对位移增量建模时 y₀ 未定义 → 默认 0 积分 → 量级放大（C 题 E4/E3）；
3. **未去噪直接变点**：原始差分噪声大 → 变点滞后（C 题 Q2：smooth_w=72 后节点 ≈8010 进官方带）；
4. **平滑/去噪方法要有数学依据**：中值滤波/SG/小波阈值需写明原理（官方 2.1 要求）；
5. **训练/实验集规律一致性声明**：题面声明"对应阶段规律一致"是分级①事实，可作预测依据，但阶段转换节点两集不一致；
6. **虚高 R²**：对水平趋势拟合回归会虚高 R²——先看变量是否真解释位移（C 题正确拒绝了水平+AR）；
7. **预警阈值分介质**：硬岩/软岩速度阈值不同（官方 5.2：硬岩 <3/3–5/≥5，软岩 <6/6–10/≥10 mm/h）——题面要分阶段，细则按介质，题面优先。

## 四、方法族-结构映射（数据驱动题通用）

| 结构 | 方法族 | 注意 |
|---|---|---|
| 线性校正（Q1） | OLS / Huber / robust soft_l1 | 交叉验证 + MAE/RMSE + 锚点表 |
| 变点/分段（Q2/Q4） | PELT / K 段 SSE 精确解 / 分段线性 | **先去噪再变点**；速度特征辅助 |
| 异常检测（Q3） | 孤立森林 / MAD / IQR | **操作定义先行**；共同异常（≥2 变量同刻） |
