## 三、关键单位/时间基准口径（红线候选）

1. **速度统一 mm/h**：任何速度量必须 mm/h（10min 采样：step 速度 = 6×相邻差分 mm/h）。
2. **时间基准**：附件1=2024-01-01 0时；附件2=2024-05-04 0时；附件4/5 实验集=2025 年（表4.1）。跨附件比较时显式标注各自基准。
3. **爆破空值 ≠ 缺失**：Q4/Q5 爆破两字段空值=无爆破事件，不得与 Q3"未填写=缺失"混同，不得进入缺失补齐流程。
4. **表3.1 字母映射固定**：a降雨量/b孔压/c微震/d深部位移/e表面位移；表3.2 用字母组合。
5. **表4.1 时间点格式**：2025-05-09 12:00 / 2025-05-27 08:00 / 2025-06-01 12:00 / 2025-06-03 22:00 / 2025-06-04 01:40（逐格对齐）。
