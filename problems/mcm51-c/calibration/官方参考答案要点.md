## 各问要点与官方数字带

### Q1 监测数据线性校正（10 = 模型 6 + 误差 4）
- 线性校正 y = kx + b，最小二乘；参考 k=0.8818、b=−0.535；MAE < 0.9 mm、RMSE < 2 mm
- 表 1.1 官方值：5.744 / 15.792 / 73.826 / 108.409 / 147.310（我们 5.764…147.310，几乎贴合）

### Q2 阶段模型与转换点（15 = 去噪 5 + 阶段划分 10）
- 去噪：中值滤波 / SG 滤波（缺扣 2）；平滑后算速度/加速度（无步骤/代码扣 3）
- 变点：PELT 等 + 加速度均值差（2 分）；分阶段二次多项式拟合（4 分）；平均速度（2 分）
- 官方节点：**8000±50 / 9500±50**（我们 8148/9573；smooth_w=72 后 ≈8010 进带）
- 官方速度：缓慢匀速 0.25 / 加速 1.75 / 快速 6.18 mm/h；R² > 0.99

### Q3 驱动因素与回归（20 = 质控流程 8 + 回归 12）
- 质控：异常检测 + 平滑去噪 + 缺失插补三环节（缺一扣 3）；孤立森林 / MAD / IQR
- 官方异常总数 **93**（降雨 21 / 孔压 24 / 微震 22 / 深部位移 23 / 表面位移 3）——我们 1123（语义过宽，E4）
- 回归：表面位移 ~ 降雨/深部位移/孔压/微震；R² > 0.9（最高 ≤0.94）；t 检验 p<0.05；F 检验 p<0.01；RMSE < 2.5 mm；实验集散点图

### Q4 多源融合分阶段预测（20 = 变点 5 + 预测模型 10 + 实验集预测 5）
- 官方节点：6200±200 / 8900±200
- 预测：分阶段 LSTM / 随机森林 / XGBoost；R² > 0.95、MAE < 1.0、RMSE < 1.5
- 表 4.1 官方：2.129 / 33.254 / 112.651 / 510.426 / 549.762（我们 7.6…1252，y₀=0 累加量级放大，E3）

### Q5 预警指标与工程应用（15 = 变量筛选 5 + 预警机制 10）
- 官方最优组合：**剔除孔隙水压力**后五变量（R² > 0.95）
- **正确识别双周期滑坡阶段（3 分）**——我们单次三段 + "恢复"当误报（E1）
- 预警阈值（分介质）：硬岩 <3 / 3–5 / ≥5 mm/h；软岩 <6 / 6–10 / ≥10 mm/h（蓝/橙/红）——题面要求分阶段，细则按介质，题面优先
