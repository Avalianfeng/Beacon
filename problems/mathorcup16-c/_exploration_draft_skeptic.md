# C 题探索草稿 S2 — 评阅人 / 怀疑者（反方）

> 角色：拆自洽套路、暴露交付遗漏与数据陷阱。独立产出，未读其他探索稿。  
> 输入：`problem.md` + 附件1轻量统计（1000×37；体质标签=5 共 278 例；高血脂阳性率约 79.3%）。

---

## 增补视角 / 隐藏评分点

1. **Q1 是双任务，不是一张相关矩阵**：前半句限定特征池为「血常规 + 活动量表」，后半句单独要求「九体质对发病风险贡献度」。只跑 `corr(血脂/活动, 高血脂标签)` 或只画九体质 logistic 系数，都缺一半交付。
2. **Q2 要的是「阈值选取依据」**，不是黑箱输出的三档概率。评阅人期待：规则/树路径/分位数/临床界值 + 为何选该切点；若阈值全靠验证集 F1 搜出来却不解释，等于吞掉题面硬性表述。
3. **Q3 正文必须出现样本 ID=1、2、3 的完整方案**（中医分级、活动强度、频次、6 个月成本、预期痰湿降幅），不是附录一句「见优化结果」。缺任一编号可直接判交付不完整。
4. **背景强调「未病先防」**，但 Q2 未排除已确诊者；Q3 又明确「确诊为痰湿体质（标签=5）」且三例样本高血脂标签均为 1。全篇若不声明「Q2 队列口径」，未病/既病叙事会自相矛盾。
5. **题面括号举例多用「可参考」「例如」**——更像评分锚点与叙事模板，不是必须复现的硬阈值；但若完全不复现且给不出等价医学叙事，容易被认为没读懂题干。
6. **附表成本/降幅公式是确定性优化题的核心约束**——不走这套公式的「漂亮 ML 干预」会被视为未建模；反之只套公式不解释「患者特征→方案」规律，Q3 后半句仍不合格。
7. **数据极端不平衡**：近八成已高血脂阳性，且痰湿积分与二分类标签相关约 0（横截面快照下「预警发病」语义脆弱）。不讨论此点，Q1/Q2 结论易被质疑为统计假象。
8. **「关键指标」隐含可测量、可干预、可复核**：仅列出 BMI 与痰湿相关，却与 Q3 中医/活动杠杆脱节，会被问「筛出来有何用」。
9. **九体质共线**：九积分同表且常同步偏高，单独回归系数不稳定；需交代正则/主成分/ dominance 口径，否则「贡献度差异」不可比。
10. **分型标签字段**：`血脂异常分型标签` 仅对确诊病例有意义；Q2 组合规则若忽略空值/占位编码，高危组合统计会假。

## 逐小问

### Q1

**主方向（一句话）**：在「血常规+活动」池内做可解释筛选（单因素+多重比较校正/稳定性筛选），九体质积分单独进入「对高血脂二分类标签的风险贡献」模型（如 logistic / SHAP / 相对风险），并区分「表征痰湿严重度」与「预警血脂风险」两套指标子集。

**最可能错在哪**：
- 把九体质积分塞进 Q1 前半句特征池（题面写的是血常规与活动量表）。
- 用高血脂标签筛「关键指标」却不谈泄漏：血脂四项本就在诊断定义里，与标签近乎同义重复。
- 只做相关性，不交付「筛选流程 + 入选指标清单 + 贡献度排序/差异」。
- 忽视标签≠积分 argmax（约 6.5%）：用「痰湿质积分」表征严重度时，与「体质标签=5」人群不一致。
- 「预警发病风险」在横截面数据上只能做「现症关联/回顾风险」，却写成前瞻性预测，时间维度缺失无自证。

### Q2

**主方向（一句话）**：可解释分层模型（评分卡 / 单调约束树 / 规则融合）输出低中高，每一档显式列出特征阈值及来源（临床参考范围、痰湿/活动题面分档、数据分位数），并单独刻画「体质标签=5 或痰湿积分高位」的高危组合。

**最可能错在哪**：
- XGBoost 三分类 + `class=0/1/2` 当高中低，正文无阈值表。
- 把括号内「痰湿≥60 / ≥80 且活动<40」当硬规则，无法覆盖 79% 阳性人群的分层。
- 训练集含高血脂二分类标签作特征 → 循环论证（用诊断预测诊断）。
- 已确诊者（标签=1）仍标「高发病风险」却不改口径为「既病加重/并发症风险」。
- 「血脂指标异常」未 operationalize：用附表正常范围、超出倍数、还是分型标签 1/2/3？
- 低/中/高三档与临床「低中高危管理」混淆：题面是血脂症 **风险等级**，不是并发症分期；档位命名需与阈值表同页出现。
- 只报告「痰湿+低活动+高血脂」一句口号，无支持度/OR/覆盖人数，「核心特征组合」交付空心化。

### Q3

**主方向（一句话）**：对标签=5 者，在附表2/3 离散方案空间内做 6 个月成本约束优化，目标函数以「痰湿积分下降」为主并写明是否兼顾血脂；输出特征分区下的最优组合规律 + ID 1/2/3 逐例表。

**最可能错在哪**：
- 目标只写 min 成本或只写 max 降幅，未声明多目标优先级。
- 忽视「每周<5 次积分基本稳定」→ 最优解系统性落在 5–10 次/周边界，却不讨论边际与耐受。
- 痰湿 58/59/61/62 边界导致中医月费跳档（30/80/130），方案对初值极度敏感却不做敏感性分析。
- 样本 1（活动 38、痰湿 64）活动强度被锁在 1 级，却排 3 级训练。
- 三例均已高血脂阳性，正文仍用「降低发病风险」措辞。
- 只给「最优」不给出「次优/不可行原因」（如超 2000、超耐受），匹配规律不可复核。
- 6 个月痰湿轨迹未列表，仅口头「显著下降」；评阅无法核对附表降幅公式是否用对。

## 红线

1. **禁止**用高血脂二分类标签（及可由血脂直接推出的特征）作输入再去「预测高血脂风险」而不声明这是「现症回顾/校准」而非发病预警。
2. **禁止** Q2 只有模型 AUC 无分档阈值表与选取依据。
3. **禁止** Q3 无样本 1/2/3 可核对方案（强度、频次、月费、总成本、预期痰湿轨迹）。
4. **禁止**忽视附表年龄/活动分档对强度可行域的硬裁剪。
5. **禁止**在 79% 阳性横截面数据上声称「发现了强预测痰湿→发病的因果链」而不加队列定义。
6. **禁止**未处理标签与九积分 argmax 不一致时，混用「标签=5」与「痰湿积分」两套人群定义。
7. **禁止**检索/引用官方参考答案与评分标准（本题自查红线）。

## 风险与 sanity check

| 检查项 | 预期/警戒 |
|--------|-----------|
| 高血脂阳性率 | ~79%；若模型「高风险」≈阳性，说明分层退化 |
| 痰湿积分 vs 高血脂标签相关 | 约 0；Q1「双效指标」可能极少，需报告「无单一血常规指标同时满足两目标」 |
| 标签=5 子集 n | 278；Q3 规律需防过拟合，交叉验证仅在同子集内 |
| ID1/2/3 可行域 | 1: 活动38→仅强度1；2: 痰湿58→中医1级30元；3: 活动63→强度1–3 可选 |
| 成本边界 | 中医 180–780 + 活动 72–1920（视档）；2000 元内通常可满配活动，「成本」未必是紧约束 |
| 频次边界 | <5 次/周无额外降幅 → 最优频次常 ≥5；若全文方案全是 5 次需解释非巧合 |
| 中医边界样本 | 58/59/61/62 分跳档；对三例中 58、59 分需写明适用 0–58 还是 59–61 |
| 确诊者进 Q2 | 若全样本建模，「高风险」多数已是现症；应改述为管理优先级 |
| 降幅复利 | 每月 -3%/-1% 是否乘性叠加 6 个月需自定；差 5–15 终积分 |
| 外部数据 | 题面允许补充；若未用需声明附件1 横截面局限 |
| 九体质 VIF/条件数 | 若 >5–10，贡献度排序对变量顺序敏感 |
| 样本 2 痰湿=58 | 贴附表2上界；误划入 59–61 档月费 +50 元 |
| 全表成本紧约束比例 | 若 <10% 患者触顶 2000，成本约束对最优解几乎无绑定 |
| Q1 与 Q2 指标重叠 | 若 Q1 入选指标与 Q2 阈值变量完全不同，需解释为何预警模型不用「关键指标」 |

**总判**：本题最易「做得像机器学习题」而丢「中医分级 + 活动耐受 + 成本公式 + 三例交付 + 阈值叙事」。反方建议主文先定 **队列口径（未病/既病）** 与 **Q3 单/多目标声明**，再选模型；否则技术路线自洽但评阅维度大面积漏项。

## 反方优先质疑清单（给主方案自检）

1. 你们的 Q2 阈值是题面举例的复刻、数据驱动，还是临床指南？三源混用须分层说明。  
2. 若去掉高血脂标签作特征，模型仍能否分出有意义的三档？不能则承认是「现症分层」而非「发病预警」。  
3. Q3 最优方案是否对 **5 次/周 vs 6 次/周** 做边际检验？未检验则「边界最优」缺证。  
4. 九体质贡献度是否报告置信区间/稳定性？共线下只报最大系数易误导。  
5. 正文是否有一张 **Q2 阈值总表 + Q3 三例方案总表**？没有则高风险漏项。
