# 文档治理约定（2026-08-26 确立）

> 本文档汇总治理阶段 0–4 确立的规则（执行路线见 [`实现计划-8-20/8-26-文档体系治理计划.md`](实现计划-8-20/8-26-文档体系治理计划.md)）。
> **约定 > 内容**：任何内容与本文档冲突时以本文档为准，并把冲突处改为符合约定。

## 一、分层与边界

| 层 | 放什么 | 维护 |
|----|--------|------|
| `docs/current/` | 人类控制面（4 页摘要：状态/计划/待决策/导航） | 每次状态回写时同步；只放摘要与指针，不复制事实 |
| `docs/` 顶层 | 体系契约 / 设计 / 范例 / 复盘 / 协议 | 持续维护 |
| `docs/实现计划-8-20/` | 落地计划与执行记录 | 批次结束后归档 |
| `docs/log/` | 自己/agent 的进度与结论时间线（全局，不属于任一计划批次） | 持续追加；不随批次归档 |
| `docs/实现计划-8-20/实际操作记录/` | 外部模型原始输出 | 只读证据，不回改 |
| `docs/archive/` | 不再维护 | 冻结；非引用不读 |

## 二、六态 frontmatter

每个活文档文件头第一行：`<!-- doc: type=<类型> status=<状态> updated=<日期> -->`

- **type**：state（事实源）/ decision（决策登记）/ contract（契约）/ plan（计划）/ design（设计）/ practice（范例）/ evaluation（复盘）/ protocol（协议）/ log（清单）
- **status**：draft（草稿）/ active（活跃）/ blocked（等待外部条件）/ deprecated（不再维护仅参考）/ superseded（已被后继取代）/ archived（archive/ 默认）
- **30 秒判定法**：看 status——非 active 的文档不得作为当前行为依据。

## 三、决策登记（07 = 决策登记表）

- 新决策自 **D-001** 起顺序编号（存量行号保留，历史引用不破坏）。
- 状态列：`accepted`（已拍板）/ `proposed`（待确认）/ `rejected`（已否决）/ `superseded`（被后继取代）——被推翻的决策**显式标 superseded，不删除**。
- **三条件判定**（值得登记才登记）：难以逆转 / 缺上下文会困惑 / 真实取舍（极简 ADR 参考 `~/.agents/skills/domain-modeling/ADR-FORMAT.md`）。

## 四、读取优先级（docs/README 〇 节）

`current/` → `00-体系现状`（事实源）→ `07`（决策）→ `实现计划-8-20/README`（计划）→ `brief-playbook`（新题必读）→ `8-27-操作面契约`（分阶段开题）→ `18`（范例）→ `20`（复盘）→ 其余 active 设计 → `archive/`（非引用不读）。

## 五、操作纪律

- **审计先行**：动手前跑 `scripts/audit_docs.py`（只读，一条命令）。
- **只读优先**：标注 > 移动 > 删除。
- **删除确认**：删除/移动/归档前逐项征求用户确认（CLAUDE.md 工作区安全）。
- **不重写内容**：只做「分层 + 索引 + 状态标注」。
- **决策留痕**：治理裁决进 07 D-xx，不留裸判断。
- **归档四件套**：压缩摘要保留（指针 + 结论）→ 原文件删除（git 可回溯）→ 引用修复 → 索引更新。

## 六、工作时间线（log/）

- `log/`（即 `docs/log/`）：自己/agent 的进度与结论；文件名 `YYYY-MM-DD-简要说明.md`（同一天多主题可多文件；文件名即索引）。全局时间线，不属于任何计划批次；批次归档时**不迁移 log/**。
- `实际操作记录/`（即 `docs/实际操作记录/`）：外部模型原始输出归档，只读证据，不回改。两目录禁止混写。
- `docs/实现计划-8-20/log.md`：已冻结（2026-08-27），不拆不改名；新日志只进 `docs/log/`。
- 写入：只允许 shell `Add-Content` 追加；禁止编辑/写入工具；写前不必读。新文件首行须带六态 frontmatter（`type=log status=active updated=日期`）。
- 审计：`docs/log/` 下日期文件豁免孤儿检查（不进 README 清单，避免每次追加还要改索引）。
