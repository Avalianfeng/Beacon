# 文档治理约定

> **约定 > 内容。** 做题用法只以 [`全流程分析/全流程定稿/`](../全流程分析/全流程定稿/README.md) 为准。

## 分层

| 层 | 放什么 |
|---|---|
| `全流程分析/全流程定稿/` | **唯一做题指导** |
| `全流程分析/讲解-一篇读懂Beacon闭环.md` | 理解面（为什么长这样）；**不是**命令源 |
| `全流程分析/图内真跑/` | 真 LLM 跑图过程经验；**不是**用法说明书 |
| `全流程分析/prompts/` | 派发模板 |
| `docs/` 顶层 | 产品定位、机制说明书、协作协议摘要 |
| `docs/current/` | 现在卡在哪（短指针） |
| `docs/log/` | 时间线，只许 `Add-Content` |
| `docs/archive/` 与 `全流程分析/archive/` | 冻结；非引用不读 |

## 六态 frontmatter

活文档第一行：`<!-- doc: type=… status=… updated=日期 -->`  
非 `status=active` 不得当现行依据。

## 决策

- 流程决策：写进定稿 00，不新开 ADR。
- 已进代码的机制：不保留 ADR。
- 学-xx：只在 `全流程分析/决策登记.md` 记流水账。

## 操作

- 审计：`python scripts/audit_docs.py`
- 以移入 archive 为主，不在现行目录留「superseded 但仍可读」的第二套说明。
- `docs/log/` 只追加；新文件首行带 frontmatter。
