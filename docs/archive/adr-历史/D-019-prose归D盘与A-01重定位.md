## 背景

- 大模块规划模块 8「论文化流程化」（**2026-08-26 登记**）范围含「论文骨架→终稿 prose 展开」（契约 T-11 / A-01 / B-02）。
- **D-007 总纲（2026-08-27）确立边界**：Beacon = 导入→骨架论文（生产段 S0–S8）；D 盘 = 论文化（改稿/出图/支撑材料/Word 交付，外 S0–S7）。D-016（2026-08-27）进一步明确评估归 D 盘。

- graph `writer_section_node` 能力仍在（D-005 降级流水线为工具层），但操作面默认不走 graph。

## 决策

**prose 展开归 D 盘**（D-007/D-016 边界确认）：Beacon 只产出**骨架论文 + evidence-package**，作为 D 盘外部 agent 写 prose 的输入。A-01 从「P0 骨架→终稿 prose 展开」**重定位**为「骨架论文 D 盘交接充分性检查」（低优先/挂账）：确保 paper.md + evidence-package 数字可溯源、结构完整，让 D 盘 agent 少返工。B-02（=A-01）**作废**。

## 后果

- **正面**：消除职责重叠（不重造 graph writer）；贴合 D-016/总纲边界；骨架论文定位清晰（=交付物）。
- **负面**：Beacon 内不产 prose（若曾期望）；骨架论文需足够支撑 D 盘——由「交接充分性检查」兜底。
- **保留**：B-01（表 3.2 清单装配）/ B-03（A2 锚点闸门）仍属 Beacon（装配/校验）；graph writer_section 为工具层可选，不主动接入操作面。
