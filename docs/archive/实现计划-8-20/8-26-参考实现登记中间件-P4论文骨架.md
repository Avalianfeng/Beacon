## 命令面

```
math-agent reference paper --problem <spec> --evidence <evidence.json>
    [--brief <brief.json>] [--out paper.md]
```

- `--brief` 缺省尝试 `problems/<id>/brief.json`；`--out` 默认 `runs/<problem_id>-reference/paper.md`。
- 逻辑：读 evidence.json + problem.json + brief.json（可选）→ 解析 q_lines（复用 P3
  `_parse_q_lines_to_fields`）→ 装配 paper.md → echo 输出路径 + 各章节字数/数字数。

## paper.md 骨架

| 章节 | 内容 | 数字来源 |
|---|---|---|
| 摘要 | 题级模板（内置 C 题默认 / `problems/<id>/paper_abstract.md` 覆盖），`{占位符}` 由 evidence 填充 | evidence.json result.ours + Q 行字段 |
| 问题重述 | problem.json questions 原文 | 题面原文（非结果数字） |
| 模型假设 | brief required_discussions disc-assumptions 的 topic + requirement，按 ①②③ 拆条、保留分级标注 | brief.json 原文 |
| 求解结果 | Q1~Q5：direction 首句（方向一句话）+ Q 行原文数字 | brief.json / evidence.json q_lines |
| 交付表 | 表1.1/3.1/4.1 三张表（复用 P3 `_build_table_rows`） | evidence Q 行字段 + tables.json 静态列 |
| 附录 A 数字溯源 | 每个关键数字 → evidence.json（result.ours 字段 / Q 行字段）或 tables.json（题面静态列）「文件 + 行号」 | 生成时实扫文件得到行号 |
| 附录 B 代码清单 | reference 目录 7 文件文件名 + sha256 | 重算自 source/reference/ |

## 摘要模板

- 内置 C 题默认模板 `_DEFAULT_PAPER_ABSTRACT`：占位符 = result.ours 字段名
  （q1_gain / q1_rmse / q2_node1 / q2_node2 / q3_common / q4_rmse / q5_rmse）或
  `<qid>.<字段>`（q1.table11 / q4.table41 / q5.thresholds_slow|accel|fast）。
- 覆盖：`problems/<problem_id>/paper_abstract.md`（纯文本/markdown，含 `{占位符}`），
  生成时在 paper.md 内注明模板来源；占位符缺失渲染为 `【待展开：<key> 未在 evidence 中】`。
- 模板/占位符是结构，不是硬编码结果数值。

## 附录 A 溯源格式（对齐 check_paper_numbers 功能 B）

- 表行 `| 论文数字 … | 来源 |`：末列 = 来源（`` `evidence.json` 第 N 行 `` 或
  `` `../../problems/<id>/tables.json` 第 N 行 ``），其余列 = 所声称数字（多值字段一行断言全部）。
- 行号生成时实扫文件 → `--traceability --strict` 可逐条断言通过。
- 标签一律不含 ASCII 数字（避免被当作所声称数字）；单数字（0–9）按工具规则视为标签噪音。
- 派生值（表3.1 总数=五行求和）不在 evidence 原文，作为派生值标注说明，不列断言行。

## 诚实边界

- 分析/推导/敏感性等 prose 一律 `> 【待展开：…】` 占位，不编造文字；所有数字必须来自
  evidence / tables.json / 题面 / brief 原文。
- 功能 A（`--paper/--evidence --strict`）会报若干"未溯源"数字，全部为：题面原文
  （问题重述/标题）、题面静态列（tables.json lead）、brief 口径数字（模型假设/方向）、
  sha256 十六进制数字段、章节/表号结构数字——**0 个真实遗漏**（无编造数字）。
