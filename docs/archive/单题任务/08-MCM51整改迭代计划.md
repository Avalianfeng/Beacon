## 三、必须着重修改的部分（按分数权重排序）

### 🔴 第一优先：问题3.1 调心垫圈定量分析（10 分，当前全丢）

**官方要求（20 分拆解）**：
- (6分) 显式函数关系：T_max(e)=500/√((1.224+0.576e)²+0.162²)，中间参数 d_e=17mm、A_e=226.98mm²、W_b=482.33mm³、W_t=964.67mm³
- (4分) 模型适用性与局限性（名义截面/应力集中、M=Pe 一级近似、Von Mises 理想材料、K_s 不恒定——四层）
- (10分) **调心垫圈定量分析**（已独立验证）：
  - 调心垫圈 = e≈0 → T_max(0)=404.97 N·m（水平参考线）
  - 无垫圈 e=5mm → T_max(5)=121.74 N·m → **提升约 233%**
  - e_cr≈3.66mm（T_max=149.88≈150 规范值）→ 超过后无垫圈无法满足 150 N·m，**调心垫圈成为必要条件**
  - 必须配图（图6：T_max-e 曲线，标注三条线 + e_cr）

### 🔴 第二优先：问题3.2 偏心压陷修正与综合模型（10 分，当前基本空白）

**官方要求**：
- (6分) 关键逻辑：**只有围岩压陷受偏心直接影响**（屈服、粘结不受影响）；偏心压陷修正 δ(e)=P(1-ν²)h₀/(E·b²)·(1+6e/b)，反解：
  T_max,indent(e)=K·d·δ_max·E·b²/((1-ν²)·h₀·(1+6e/b))
- (4分) 综合四约束 T_max(e)=min{T_yield, T_bond, T_indent(e), T_VM(e)} + 至少一组数值验证 + **全范围 Von Mises 等效应力为主控约束**的结论（T_VM(0)≈405 < T_yield≈612）

### 🟠 第三优先：问题1.2 变点检测（10 分，当前方向性错误）——代码思路转向

**官方要求**：突变点识别模型；岩石 T_c∈[100,150]、煤体 T_c∈[150,200]；对 T≥T_c 数据建立线性回归。

**整改**（算法：分段线性回归 + 网格搜索）：
1. 表2/表3 五测点预紧力按 T 均值化（岩石：3.962/9.122/14.754/21.296…）
2. 候选 T_c 扫描：岩石 {100,125,150}、煤体 {150,175,200}
3. 对 T≥T_c 数据线性回归 P=aT+b，计算 SSE/R²
4. 选最优（官方参考：岩石 T_c=100→P≈0.234T−0.15，150→0.217T+4.02；煤体 150→0.162T+1.31，200→0.174T−2.28；R²>0.99）
5. 论文写法：给 T_c 区间 + 推荐值 + 敏感性，**不声称唯一确定**（评分标准允许区间内任意值 ±5%）

### 🟠 第四优先：问题2.2 工况B（20 分里的 10 分）——代码模型结构转向

### 🟡 第五优先：问题4 围岩分级与统一模型（10 分）——思路转向

**官方要求**：
- (4分) 围岩分级（≥3 级）：f<3 软岩 / 3≤f<6 中等 / f≥6 坚硬（题目正文明确）+ 各级主控失效模式（C1–C4 四约束）
- (6分) T_opt(f)=min{T₁(f), T₂(f), T₃(f), T₄} + argmin 主控判定 + 可靠性验证

**整改**：
- 结构：T₁=K·d·P_yield（水平线）；T₂=K·d·π·D_hole·L_bond·(0.25E(f)+1)·10⁻³；T₃=K·d·δ_max·E(f)·b²/((1-ν²)·h₀)；T₄=T_VM(e)（与 f 无关）
- f→E 映射：**参数化假设** E(f)=E₀(f/f₀)^m + 敏感性分析（官方开放，但必须声明假设、不得伪装唯一）
- 主控判定：i*(f)=argmin T_i(f)，按 f 分区（软/中/硬）
- 结论方向（r11 定性已对）：低 f 压陷控制、高 f 屈服控制——保留并补数值

### 🟡 第六优先：问题2.1 公式对齐（10 分里的 4–5 分）
