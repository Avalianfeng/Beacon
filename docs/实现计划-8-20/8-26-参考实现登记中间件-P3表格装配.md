## tables.json spec 格式（声明式）

顶层 `{"tables": [...]}`，每张表：

| 字段 | 必填 | 含义 |
|---|---|---|
| `id` | 是 | 表标识，决定输出文件名 `<id>.md` / `<id>.csv`（如 `table11`） |
| `title` | 是 | 表标题（md 首行标题，如「表1.1 位移数据校正验证」） |
| `columns` | 是 | 列名列表（字符串），列顺序即输出顺序 |
| `lead_columns` | 否 | `{列名: 静态题面值列表}`——题面给死的列（如校正前 x / 时间点），逐行填 |
| `field` | 否 | `"<qid>.<字段名>"` 指向 evidence Q 行字段（值必须为列表），按「未被 lead_columns 覆盖的剩余列」顺序逐行填 |
| `total` | 否 | `true` 时末列填本行数值格之和（如表3.1 的「总数」） |

行数约束：lead_columns 各列与 field 列表长度必须一致；field 值数须等于剩余列数
（`total: true` 时等于剩余列数−1，末列留给合计）。
