## 一、v2 核心修正（2026-08-21 采纳外部评估意见，逐条有落点）

1. **先探索、后收敛；不接受「强模型一次性产出极高方向」**。MCM51-A 失败解剖（[archive/08](../archive/单题任务/08-MCM51整改迭代计划.md)）：
   1.2 该变点检测却走力学 min、3.1 调心垫圈整题漏做——不是模型不够聪明，而是**建模视角在解题前
   就没进入认知空间**；且同一模型自审发现不了（H04 相关判断者）。**先问「这道题可能要求我们看到什么」，
   再问「我们应该怎么解」**——方向质量靠四道结构保险，不靠模型天赋：
   1. **开放探索（2026-08-21 晚新增）**：建模前由人+强模型+联网先扩大认知覆盖（出题人/评阅人/建模者
      多角度），产出方向性认知地图；不做触发规则库（枚举式规则覆盖不了未知的遗漏）；
   2. **多模型独立提案 + 对撞**：2–3 家不同家族各自独立出全套方向方案（互不看），人主持 diff，
      分歧点逐个裁决——目标是暴露遗漏（A/B/C 之外是否还有 D），**不是投票定方向**；
   3. **逐问清点 checklist**（结构化提示词包）：交付物类型 / 出题人想看什么（题面措辞线索）/
      消耗哪些附件 / 候选方法族 ≥2 + 淘汰理由 / 单位口径 / 必配图表；
   4. **廉价 pilot 早反馈**：跑到 coder 首轮 execute 出数即停，一页简报（关键数值/单位/
      与题面数据对账/每问方向一句话），人（或外部强模型）确认后放行全跑——成本约全跑 1/10。
   → 落点：①②③ [docs/brief-playbook.md](..\brief-playbook.md)；④ [09-pilot模式与早期反证](09-pilot模式与早期反证.md)。
2. **工程重心与证据结论对齐**：值得投入的只有三件事——①堵传递漏点（M3 红线机器化、M2 图表注入，
   均有 brief-v1 实证漏分记录）；②brief 生产过程产品化（playbook）；③错误方向廉价早发现（pilot）。
   其余机制工程降级/冻结（见 §四）。
3. **治理收缩**：文档冻结增量——不再开新编号体系（H/C/B/M/O/G/D 类到此为止），新知识回填现有文件；
   大盲测集降级；前端重设计降级为独立计划 [10](10-前端与新题入库-简化计划.md)（最简单模式）。
