## 二、目标结构与边界定义

| 层 | 放什么 | 边界 |
|----|--------|------|
| `docs/` 顶层 00–17 | 体系契约/设计/评估/路线图 | 持续维护 |
| `docs/18` | **可迁移范例**（怎么做题的全流程实录 + runbook + 规范） | 活文档，新题后更新 |
| `docs/20` | **赛后评估复盘**（每题一例；≥3 例后迁 `赛后评估/` 子目录） | 赛后写入 |
| `docs/19` | 设计稿（双线路融合） | 冻结为设计记录或转正 |
| `docs/brief-playbook.md` | 方向生产协议 | 持续维护 |
| `docs/实现计划-8-20/` | 落地计划与执行记录 | 批次结束后归档 |
| `实际操作记录/` | 探索原始证据（第一论 3364 行等） | **只读**；README 已索引 |
| `archive/` | 不再维护 | 引用检查后冻结 |

**经验教训三处边界**：18 = 可迁移做法；20 = 单题复盘（含根因）；实际操作记录 = 原始思考证据。
**8-26 系列命名**：保持 `8-26-` 前缀（log/07 已引用，重编号成本 > 收益），作为"日期批次命名空间"。
