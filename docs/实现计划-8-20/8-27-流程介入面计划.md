## 一、产品定义（混合路线一句话）

Beacon 的产品面是：**人 + 外部 agent 能按阶段驱动、停、注入、交下一棒的操作面**。  
流水线是其中一条可选执行器，不是默认无人值守主路径。

```
人 / 外部 agent
    │  读阶段契约 → 调命令/skill → 写回产物 → 决定下一棒
    ▼
操作面（本计划要建）
    ├── 方向生产   brief-playbook（已有，协议层）
    ├── 导入/盘点  problem import/show · brief init · run --dry-run（已有）
    ├── 求解验证   参考实现 + reference add/run（已有）→ evidence-package（缺口）
    ├── 论文装配   reference tables/paper（已有）→ 终稿 prose（模块 8 残项）
    ├── 评审闸门   check_* 脚本族（已有，未收成命令）
    └── 可选执行器 LangGraph start/supervise + pause/restart（已有，默认不再当唯一入口）
```
