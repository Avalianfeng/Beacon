## 四、本次执行方案（跑法已由用户确认）

**跑法**：主会话统一管理 + 子 agent 分工（探索/数据探查/求解/写作/评审各派子 agent，产物回主会话统一协调与校验）；**不跑轨 A 流水线**（C 题跑通后再评估）；**多模型对撞用"多角色分工 + 独立产出 + 人主持 diff"近似**（子 agent 同模型，独立性受限，如实声明）。

**步骤**（仿 mcm51-b + 8-26 机制）：

1. **题目导入**：`problem import` → `problems/mcm51-c/`（problem.json spec v2 + source/：题面 md、docx、5 个 xlsx 附件；data_files 摘要：sheet/字段/规模）
2. **素材盘点 + 数据探查**（C 题特有新增环节）：子 agent 读 5 个 xlsx 出**数据画像**——规模/字段/时间范围/量纲/缺失分布/爆破空值模式/噪声与跳变观察（Q1–Q5 各附件分别画像）
3. **开放探索**（brief-playbook §2.1 提示词，直接复制 + 按数据驱动题微调）：子 agent 产出思考路径（数千行候选点），归档 `实际操作记录/第一论-C.md` 式
4. **探索消化**（§2.5 第二轮追问）→ 认知地图 v1（100–150 行）→ `problems/mcm51-c/exploration.md`
5. **多视角对撞**（§3 提示词；角色分工近似）：出题人/评阅人/建模者/怀疑者/数据分析者角色独立产出 → 人主持 diff → 分歧裁决
6. **逐问清点**（§4 checklist）：交付物类型/出题人想看什么/消耗附件/候选方法族≥2/单位口径/必配图表 + "我们有没有可能完全没看到某个重要因素"
7. **方向收敛 → brief**：`brief init` → 填充（per_question_direction/formula_notes/red_lines/required_discussions/data_notes…）→ `brief check` [OK]；**口径防线应用**：假设分级标注、弱依据禁令进备选口径、题面信号清单（C 题信号：表模板、训练/实验集同规律声明、爆破空值语义、时间频率 10 分钟、速度单位 mm/h 等）
8. **求解（agent 写脚本，按 B 类五条规范）**：数据预处理（去噪/补齐）+ Q1–Q5 各问模型（校正/变点识别/异常检测/关联分析/分阶段预测/变量组合选优/预警阈值）+ evidence.md（数字→文件+行号）+ 诊断输出；脚本 sha256 登记
9. **评审（C 类四必答项）**：子 agent 评审 + 三个 check 工具跑（假设矛盾/大 gap/数字溯源）
10. **论文（轨 B 式）**：writer agent 产出 paper.md（八 discussion/表齐全/诚实声明/零编造回源）→ 数字白名单闸门（check_paper_numbers --strict）
11. **论文化**（如用户要求）：D 类进稿闸门；附录 B 代码自动装配（本次不要留空，上次扣分风险）
12. **收尾**：log.md 追加；git 提交；产物目录规范（problems/mcm51-c/ + runs/ 或工作面）
