# ADR 怎么写（现行）

流程怎么走：**不在这里写。** 只看 [全流程定稿 00](../../全流程分析/全流程定稿/00-正式闭环.md)。

## 规则

1. **已进代码的机制**（coder LLM 默认关、inject、门禁一次停、brief 硬信号等）不写 ADR，代码和测试就是记录。
2. **做题/协作流程**不写 ADR，写进全流程定稿。不要再叠 D-028/029/030 这种互相解释的长文。
3. **只有**尚未落地、且有真实取舍、07 一行写不下时，才在本目录新增一篇。模板：背景 / 决定 / 不选什么。写完尽快落到定稿或代码，然后把 ADR 移进 archive。

## 历史

全部旧 ADR 在 [archive/adr-历史/](../archive/adr-历史/)。其中包括已落地的 D-022～026，以及已被定稿 00 收口的 D-028～030。翻历史可以，不要当现行。
