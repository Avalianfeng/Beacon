# D-016 · 盲测重定位：现有流程即盲测（16 阶段 1 降概念参考，D4/D5 清理）

- 日期：2026-08-27（P-04 模块 6 + P-05 用户拍板）｜ 状态：accepted → ✅ 已执行
- 决策编号：07 决策表 D-016

## 背景

- 16 路线图阶段 1 = 盲测（原 12–20 题大基建，2026-08-21 降级为 3 道干净题 + 输出冻结后自评）；决策点 D4（采纳盲测治理阈值）/ D5（Go/No-Go 三选一）待批。
- D-011 把 mathorcup16-c 降格为实验性后，**干净题候选 = 0**：mcm51-a 已污染开发集；mcm51-b/c 已接触官方答案（赛后校准）。
- 用户澄清实际流程：**新题在 Beacon 生产段全程不看答案 → D 盘论文化 → 赛后评估报告**（如 `D:\数学建模\工作面\51mcm-c-word-r1\赛后评估\最终评估报告.md`，B/C 均有得分）——每次新题真跑本身就是一次盲测样本（单题）。
- 评估/验证类工作（得分评估、口径校验、复盘）已实际发生在 D 盘赛后流程，Beacon 内另设盲测机制 = 重复验证 + 概念负担。

## 决策

**盲测重定位**：现有新题流程即盲测，不再另设「干净题集 + 输出冻结自评」；16 阶段 1 降为**概念参考**、不作为体系待办；**D4/D5 不再占待决**（不堵塞工作则清理干净）；验证/评估类内容后续在 **D 盘评估流程**中考虑，不在 Beacon 加新机制。

## 后果

- **正面**：概念面简化（无重复验证机制）；评估贴近真实交付流程（D 盘赛后即评估）；待决清单收敛；盲测相关挂账（E-01/E-05 ★项）降级。
- **负面**：**永远没有"干净读数"**——体系能力结论停留在「方向决策的高保真执行器」（H02），无法回答「陌生题无参考能得多少分」；16 文档阶段 1~4 部分章节降为概念参考（保留作将来重建盲测的规格）。
- **兜底**：每次新题真跑的赛后评估（D 盘）仍提供单题真实证据；15 智慧中枢复评触发条件保留（E-06）。
