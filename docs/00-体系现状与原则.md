# 体系现状与原则

## 一句话

本仓是 Beacon 的 fork：本地 agent 探索、写代码、算数、起草 brief；**算完之后启动 LangGraph**（coder LLM 默认关），用 brief 驾驭方向，用登记代码当改代码插座，critic 驱动手改，直到图跑通产出论文。

不是：本地写完论文即结束。也不是：无人值守从零 codegen 出赛。

## 仍约束设计的原则

1. 不得把某次数值命中写成通用能力。
2. 不重写核心流水线架构（节点/证据链）；前端壳除外。
3. 不启用向量检索。
4. 交付以 `.md` 为主；PDF 仅预览。
5. 方向错了改 brief 再跑；体系内不做无依据投票。
6. 硬信号（执行输出、机器校验）优先于软评分。
