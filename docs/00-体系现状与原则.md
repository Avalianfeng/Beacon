## 一、我们在做什么（一句话）

本仓是上游 Beacon 的 **fork**：把「一键跑完整 LangGraph 图出 PDF」改造成
**受人工策略约束的建模执行与论文生产平台**——前置（人+强模型+联网）先做题目探索与 Modeling Brief，
人 / 外部 agent 按 S0–S8 分阶段驱动；质量靠执行证据与后置机械闸门兜底。流水线仍在，但是可选工具（S9），不是默认主路径（D-002 / D-005）。

> 更短的说法：**方向决策的高保真执行器 + 论文装配器**（H02）。通用无参考求解能力未当作已验证能力宣传。
> 方向协议：[brief-playbook](brief-playbook.md)。端到端：[内外全流程总纲](内外全流程总纲.md)。相对上游差异：根 README「相对上游改了什么」。

## 二、核心原则（约束；改动需论证）

1. **参考答案不可得**：brief-v1 的数值命中是意外特例，不是通用能力；不得把数值注入写进通用路线图。
2. **以工程完善体系为第一目标**：前置质量（**题目探索 + 方向生产**）+ 竞争假设 + 运行证据 + 后置校验**四层共同防御**（不把质量责任单向后移）；单次任务的成功不得污染通用设计。（C1 已采纳，2026-08-20）
3. **不重写架构、不开新项目**（近期约束；Go/No-Go 决策点可重议，C3 已采纳）：节点与证据链机制是 11 轮踩坑积累，重写=重踩 P01–P20。**豁免：前端壳允许整体重设计**（D6 已批准，2026-08-20——前端是交互层、不承载求解逻辑，不在体系讨论范围；核心流水线仍守本原则）。
4. **当前不启用向量检索**（实现选择：embedding 网关不支持；C4 已采纳）：检索需求由文本资料包前置注入满足（本质是受控检索）；网关可用后重评估。
5. **前置只承诺方向级+实现级**；验收级数值锚点只能从题目自带数据+量纲一致性+领域常识重建。
6. **brief 产出路径：题目探索 → 认知地图文档 → 提取 brief**（文档+提取为主，对话兜底）；探索由人+强模型+联网在前置完成（先扩大认知空间，再收敛方向）；`brief extract` 命令方向已定、暂不实现。
7. **最终产物以 .md 为主**：`paper.md`（+`paper.tex` 源码）是交付物；PDF 仅用于 LaTeX 链路验证与预览，**不承诺完整可交付**；版式/格式调整由后续人工流程手动进行，提交前必有再处理流程（2026-08-20 确认，H15）。
8. **方向在源头定，错了回源头改 brief 重跑**；体系内不做**无依据的 LLM 投票式**方向评审，但允许基于确定性证据（残差/量纲/边界/对照实验）的方向反证（C2 已采纳，2026-08-20）。
   **前置多模型对撞 ≠ 体系内投票**（2026-08-21 明确边界）：对撞在前置、人主持、目标是**暴露遗漏、扩大搜索空间**（先问「A/B/C 之外是否还有看不见的 D」）；多模型一致不构成方向正确性证据——**多模型负责发现更多可能性，确定性证据负责淘汰错误可能性**。

## 四、体系怎么工作（模块与链路）

- **默认路径（操作面 S0–S8）**：导入 → 探查 → 探索/brief → dry-run → 求解验证 → `reference` 登记/跑数/表/骨架/`expand` → `review-check` → `accept`。细则：[操作面契约](实现计划-8-20/8-27-操作面契约.md)。
- **前置方向生产**（流水线之外）：探索 → 认知地图 → brief。协议：[brief-playbook](brief-playbook.md)。方向错了回源头改 brief。
- **可选 S9 流水线**：analyst → blueprint_critic → modeler → model_critic → coder → model_code_consistency → sensitivity → figure → writer → paper_critic → evaluation → human_review → latex → finalizer。无 T-19 / `source/inject/` 时 coder **不调 LLM**（D-024）；四门禁首次未过即 stop（D-023）。
- **brief 硬信号（D-022）**：有序块表 `NODE_BRIEF_SLICE`；schema v2 `redline_rules`；hard 恒停；S7 记 `brief_sha256`。
- **核心机制**：证据链（checkpoint + 哈希）；机械闸门（`check_paper_numbers` / L4 / 红线 / claims）；角色隔离（primary/baseline/supporting）；冻结资产直接执行（T-19）；崩溃恢复（recover / restart）。
- **协作边界**：agent 写代码与算数；Beacon 产论文 + 机械校验；工作面做 Word / 赛后。[agent协作协议](agent协作协议.md)。
- **模块清单**：`cli.py` 操作面入口；`graph.py`/`routing.py` S9；`brief.py` + `source/inject/`；`frozen_asset.py`；`nodes/` + `prompts/`；`llm.py`；`supervisor.py`；`rag/`（不启用）；`scripts/check_*.py` 闸门。
