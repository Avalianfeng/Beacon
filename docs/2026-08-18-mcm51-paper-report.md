## 二、问题建模与主要结果

### 问题 1.1：预紧力矩与预紧力关系模型

- **建模**：稳定工作阶段预紧力矩与预紧力满足线性关系 $T = K d P$，采用最小二乘回归估计扭矩系数 $K$（无截距模型，$K = \frac{\sum d_{m,i} P_i T_i}{\sum (d_{m,i} P_i)^2}$），以 $R^2$ 衡量拟合优度。
- **结果**（基于附件表1 标准实验数据）：

| 口径 | 扭矩系数 K | R² |
|---|---|---|
| 整体拟合 | 0.176681 | 0.958852 |
| 直径 18.0 mm | 0.162003 | 0.966272 |
| 直径 20.0 mm | 0.183069 | 0.987376 |
| 直径 22.0 mm | 0.189868 | 0.993835 |

- **结论**：分直径拟合 R² 均高于 0.96，线性模型在实验范围内高度适用；扭矩系数随直径增大而增大。

### 问题 1.2：临界预紧力矩

- **建模**：临界预紧力矩定义为系统不发生任何失效模式的最大预紧力矩，由统一模型 $T_{crit} = K d \cdot \min(P_y, P_b, P_{\delta})$ 确定（$P_y$ 屈服载荷、$P_b$ 锚固剂粘结力极限、$P_{\delta}$ 围岩压陷允许载荷）。
- **结果**（基于工况A参数：直径 20.0 mm、屈服载荷 170000.0 N、锚固长度 800.0 mm）：$P_y=170000.00$ N、$P_b=188545824.70$ N、$P_{\delta}=360000.00$ N，$P_{max}=170000.00$ N，临界预紧力矩 **600.71 N·m**。
- **说明（论文已如实声明）**：该值由工况A参数计算得出；附件表2（岩石工况）、表3（煤体工况）提供的实测预紧力矩范围为 25~300 / 25~375 N·m，本文计算值超出该实测范围，两者口径不一致；论文未将表2、表3 的测点数据用于临界点识别，该局限已在模型评价部分如实说明。

### 问题 2.1：最大允许预紧力矩通用参数化模型

- **建模**：以预紧力矩 $T$ 为决策变量，$P$ 由 $T=K d P$ 确定，系统需同时满足三类失效约束：
  - 锚杆屈服：$P \le P_y$；
  - 锚固剂粘结：$P_b = \pi d l \tau$，$\tau = 0.25E + 1.0$ MPa；
  - 围岩压陷（Winkler 弹性地基）：$P \le k A_b \delta_{max}$，加钢带后有效承压面积 $A_{eff} = A_b + A_{steel}$。
- **钢带必要性判据**：当 $P_{\delta} < P_y$ 且 $P_{\delta} < P_b$ 时，围岩压陷成为主控失效模式，必须加钢带。
- **模型**：$T_{max} = K d \min(P_y, P_b, P_{\delta})$。

### 问题 2.2：工况 A 与工况 B 计算

- **结果**（基于附件表4 工况参数）：

| 项目 | 工况A（岩层锚杆） | 工况B（煤层锚杆） |
|---|---|---|
| 直径 / 屈服载荷 / 锚固长度 | 20.0 mm / 170000 N / 800 mm | 22.0 mm / 205000 N / 1200 mm |
| 屈服 $P_y$ | 170000.00 N | 205000.00 N |
| 粘结 $P_b$ | 188545824.70 N | 41551961.07 N |
| 压陷 $P_{\delta}$ | 360000.00 N | 110769.23 N |
| $P_{max}$ | 170000.00 N | 110769.23 N |
| **$T_{max}$** | **600.71 N·m** | **430.56 N·m** |
| 钢带必要性 | 否 | **是** |
| $T_{opt}=0.8 T_{max}$ | 480.57 N·m | 344.45 N·m |
| 安全裕度 | 0.2000 | 0.2000 |

### 问题 3.1：偏心受力模型与适用性分析

- **建模**：偏心距 $e$ 引入附加弯矩 $M=Pe$，按第四强度理论建立等效应力约束：
  $$\sigma_{eq} = \sqrt{\left(\frac{P}{A_e} + \frac{P e}{W_e}\right)^2 + 3\left(\frac{T}{W_t}\right)^2} \le \sigma_s$$
  由等效应力方程解出 $P_y(e)$，得 $T_{max}(e) = K d P_y(e)$。
- **适用性**：模型基于名义截面简化假设，适用于小偏心情况；偏心距较大时截面可能进入塑性、二阶效应不可忽略，需修正。

### 问题 3.2：多失效模式修正模型与数值验证

- **建模**：修正模型综合偏心屈服、粘结、压陷约束：$T_{max}(e) = K d \cdot \min(P_y(e), P_b, P_{\delta})$。
- **数值验证**：附件未提供偏心数据，按规范取 $e=0$，此时 $P_y(0)=P_{y0}$，修正模型退化为问题2.1 模型。验证结果：工况A 600.71 N·m、工况B 430.56 N·m，与问题2.2 一致，模型一致性成立。

### 问题 4：基于普氏系数的最优预紧力矩模型与主控失效模式

- **建模**：普氏系数 $f$ 与围岩弹性模量 $E$ 取经验关系 $E = f \times 10^9$ Pa；$T_{max}(f) = K d \cdot \min(P_y, \pi d l (0.25 f + 1.0) \times 10^6, k(f) A_{eff} \delta_{max})$；最优预紧力矩取安全系数 $\eta=0.8$：$T_{opt}(f) = 0.8 T_{max}(f)$。
- **结论**：不同 $f$ 区间主控失效模式为——低 $f$ 时围岩压陷控制，高 $f$ 时锚杆屈服控制；模型验证与工况 A/B 数值一致。
- **局限（论文已如实声明）**：缺少 $f$ 扫描的具体数值，主控失效模式的切换阈值未能定量给出。

## 四、模型假设摘要

1. 锚杆材料理想弹塑性，von Mises 等效应力，屈服强度为常数；
2. 扭矩系数 $K$ 在给定工况下为常数（线性回归确定）；
3. 围岩压陷采用 Winkler 弹性地基模型，钢带有效增大承载面积；
4. 偏心附加弯矩按 $Pe$ 计算，忽略二阶效应；
5. 螺纹有效直径 $d_e = 0.85d$，截面系数按圆截面计算；
6. 安全系数 $n=1.0$（许用应力等于屈服强度）。

每条假设均附依据与合理性分析（见论文第 2 节）。

## 五、模型评价与局限（论文已如实声明）

**模型优势**：
- 综合考虑偏心受力和围岩压陷等实际因素；
- 分直径回归 R² 均超过 0.96，数据拟合良好；
- 统一的多失效模式约束模型便于工程应用。

**模型局限（论文正文第 5、7 节）**：
1. 问题1.2 的临界预紧力矩直接采用工况A 的 $T_{max}$，未利用表2/表3 数据进行分段线性拟合或残差对比，与题目要求不完全一致；
2. 问题4 主控失效模式仅给出定性结论，未提供 $f$ 扫描的具体数值或阈值，模型验证不足；
3. 敏感性分析未进行定量参数扫描，缺乏扰动幅度和敏感度系数；
4. 全文图表数量不足（当前 1 张回归图），关键结果（T_max 对比、f 敏感性）缺乏可视化；
5. 扭矩系数 $K$ 常数假设、单锚模型（未考虑群锚效应）、偏心模型仅适用于小偏心。

**推广方向**：引入螺纹副摩擦系数随预紧力变化的接触模型、锚杆群效应数值模型、$f$ 参数扫描确定主控失效模式切换临界值、偏心距敏感性量化。
