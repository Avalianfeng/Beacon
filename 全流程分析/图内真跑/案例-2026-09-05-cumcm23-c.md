### 4.1 多次 8/10，`edit_paper`

门槛 `MIN_PAPER_CRITIC_SCORE=9`。issues 类型随重写漂移：

1. **假设越权**：「题目要求」把销量当需求代理（题面没写死）。
2. **写了没用的假设**（补货倍数上限，公式里只有 `q=d̂/(1-λ)`）。
3. **评委要未执行方法**：分位数回归、缺货惩罚、单品级预测。
4. **general：正文未引用 11 张图**——这是系统问题，不是文笔。

插图发生在 `render_markdown` / latex 的 `interleave_figures`。评委读的是章节字符串。正文没有「图 n」就会判未引用。

只 `restart --from writer`、不改提示，会换一批 nit，**图号问题还在**。

### 4.2 系统侧三刀（过闸所必需）

1. **确定性引图**：`ensure_figure_citations` 在分节写完后补「如图N所示」+ analysis。
2. **假设消毒**：plan 里「扫参参数名必须用 cost_shock…」进了假设 5/6，评委当工程泄漏。写作视图 + `_clean_forbidden_words` 剥内部标识。
3. **否决门槛**：编造 / 不一致 / 完全不引图才 `approved=False`；未实现方法进 suggestions。

第三次 writer 续跑（清泄漏 + 收门槛）后：`paper_critic` **9 / approved**，边走到 `table_assembler`。

过闸当次评委仍列出假设口径、Q1 方法过简、Q4 缺定量联系、单因素扫描等——但按新门槛这些不单独否决。

## 6. 真实命令（可抄，路径以本题为准）

```text
uv run math-agent run --problem problems/cumcm23-c/problem.json --brief problems/cumcm23-c/brief.json --plan problems/cumcm23-c/plan.json --out runs/cumcm23-c-graph-r2 --no-interrupt

uv run math-agent reference add --problem problems/cumcm23-c/problem.json --solver problems/cumcm23-c/source/reference --entry _entry.py --force

uv run math-agent restart --out runs/cumcm23-c-graph-r2 --from coder --reason "打开声明附件并落盘研究图"
uv run math-agent restart --out runs/cumcm23-c-graph-r2 --from writer --reason "按 paper_critic 意见重写"
```

并行对同一 `--out` 再 restart → `checkpoint 未处于停机态（next=('writer_section',)）`。等当前 worker 结束。
