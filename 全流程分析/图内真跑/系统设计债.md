## 操作面

| 债 | 状态 | 说明 |
|---|---|---|
| 同一 `--out` 并行 restart | 仍开 | 第二发会 `REJECT`（next=writer_section）。应在 CLI 先抢锁再判停机态，或提示「已有 worker」 |
| `/health` 不能代表网关可用 | 仍开 | 探针用 `/v1/models` |
| `--strict` 只核关键 RESULT | 落地 | 年份/题面/文献不挡闸；G1 与 caption 逐字改为 WARN |
| 同 stdout 对照 | 落地（有结构条件） | 独立 `RESULT: baseline=<名>` 且与 ours 指标可比、数值不同。Q 行对照仍不算。本题 r2 因此对照仍为 0 |
| finalizer `degraded` | 仍开 | 页数≥20、Overfull 未改；r2 对照仍 0（Q 行不是 RESULT 行） |
| `--no-interrupt` 跳过人审 | 产品如此 | 16 验收明确：跑完图 ≠ 人已验收 |
| paper_critic 只看章节摘录 | 仍开 | `build_prompt` 对长节做头+尾截断；引图若只在中部，评委当没引。补引放节末才能进摘录尾 |
| 表在 critic 之后才装配 | 仍开 | `table_assembler` 在 `paper_critic` 之后，评委看不到正式表，会说「敏感性无运行证据」 |

## 以后优先改（若再做系统）

1. **plan 假设拆字段**：人读 `statement` / 机读 `inject_param` 分开，从源头杜绝论文泄露。
2. **restart 与 RunLock 顺序**：先锁目录，避免「判了停机、另一进程已经在写」。
3. **figure 资产检索**：不要强迫 `_entry` copy PNG。
4. **对照方案质量门**：同 stdout 已认独立 `RESULT: baseline=<名>` 行。Q 行对照仍不算；要绿须在 `_entry` 补 RESULT 行或单独登记对照。
5. **paper_critic 双通道**：LLM 出建议；硬否决只做编造/不引图/上游未过——少靠 prompt 收口。
6. **评委摘录窗口**：长节只送头尾；确定性引图必须落在节末（或扩大/取消摘录）。
7. **表装配时序**：若希望评委看见表，把 `table_assembler` 挪到 `paper_critic` 之前，或评委提示「表在终检不在初评」。
