# 09 · 逐问清点（拍板 → 研究开工的边界图）

> **第一幕收口。** 总图：[00](00-正式闭环.md) ⑤ → 下一站 [10-研究会话](10-研究会话.md)。  
> 理解面：[讲解 §2 末](../讲解-一篇读懂Beacon闭环.md)（方向怎么长出来）；本题状态见题内 `认知地图集/README.md`。

## 这一段在防什么

拍板只有几条带编号的**方向选择**，直接开研究会出事：长会话中途反复回问口径（打断研究节奏），或研究者**悄悄收窄/放宽某问而不被察觉**（方向漂移）。逐问清点是把拍板翻译成研究开工的**边界图**：每问能做什么、不能做什么、哪些口径已分级、题面里藏着哪些没明说的约束。

另一条防线相反：**草稿可用即可，不许为完美拖延研究**（学-21：为填表而填表是研究阶段最贵的浪费）。所以本站人闸是"草稿级点头"，不是"定稿级审查"。

## 输入（此刻题根已有什么）

- `认知地图集/diff/diff.md`（综合与拍板建议）
- `认知地图集/清点/00-拍板表.md`（人已拍板、主会话已登记，含 8 条编码）
- `认知地图集/清点/主线.md`（拍板的主线压缩）

## 怎么做

1. 主会话起草：按拍板主线写 **Q1–Q4 逐问分解表**（每问：拍板取向 → 允许范围 → 禁止/越权 → 待研究验证项）＋ 题面**隐藏约束**清单 ＋「**有没有没看到**」自查（扫题面原文找被跳过的句子）。
2. **口径分级尽量让**人点头：哪些问法定死、哪些留给研究定（分级不一致正是研究要解决的，不用现在统一）。
3. 人改/点头后，把 `领域知识.md` 补到位（预检 d007 引用它；缺了只是非硬挡，但研究迟早要它）。
4. 更新 `认知地图集/README.md` 状态行（本夹的惯例索引）。

提示词：`prompts/清点/模板-提示词A.md` · 时机约束：`prompts/清点/说明-diff后才用.md`（本地/diff 期间禁做）。

## 边界

- 禁读：他题/联网题解；产本地地图与 diff 的阶段禁做本站（先拍板）。
- 人闸：清点草稿点头即可，**不挡开研究**；未点头也可进 10（学-21）。
- 可推翻：清点里的口径分级与拍板同级——研究用数据推翻时，账记 `_研究日志.md`，不回头改清点措辞。
