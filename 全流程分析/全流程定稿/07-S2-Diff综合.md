> Diff 不是独立职业；人拍板后**同一对话可续跑**进 [10](10-s5-求解推进.md)。

## 谁 / 产物 / 人闸

| | |
|---|---|
| 谁 | **人新开干净对话**粘贴 Diff 派发；主会话不 Task 代派 |
| 产物 | `diff/_预构想.md` + `diff/diff.md`；可自管 scripts/data/figures |
| 人闸 | 抽查六段与**当时**未滑成完整竞赛解；再进拍板 |

## 硬顺序（防锚定 · 仅 Diff 段）

```text
只读题面/数据 → 锁存 _预构想.md → 才读外部地图+本地地图
→ 比较 / 综合 / 验证 → diff.md（六段）
```

六段：预构想摘要 / 共同 / 冲突（口径·证据·解释·方法）/ 结合机会 / 验证结果 / 拍板≤8 + 可推翻。

## 边界（Diff 段）

可用代码验证结合方向；**此段**不闭合成进货表/最优价。  
学-21：拍板之后若**续同一会话**做长研究，边界切换为「题根实验室 + 研究目标」，见 10-s5。

## 续跑（学-21）

Diff 交卷 + 人拍板后：

1. **优先**：同一对话粘贴 `prompts/研究/` / 本题 `_派发/研究.md` 的续跑段，进入长研究；或  
2. 新开研究会话（上下文从工作区重读，不依赖聊天记忆）。

不要把 Diff 当终局答案键；也不要为维护 diff 措辞而强行解释后续数据。
