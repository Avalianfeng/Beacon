# 08 · 拍板登记（判断责任归人，落盘成工作假设）

> **第一幕 · 人裁决。** 总图：[00](00-正式闭环.md) ⑤ → 上一站 [07-Diff综合](07-Diff综合.md) → 下一站 [09-逐问清点](09-逐问清点.md)。

## 这一段在防什么

双图撞出的候选方向是"综合"不是"决定"。决定只能人做——机器可以给信息，不能替人承担方向责任（拍错板要人负责）。拍板后的形态也刻意压成**当前工作假设**：研究阶段允许、也预期用数据推翻它（推翻要记账）。拍板是研究的地图，不是研究的牢笼。

登记（主会话）的意义：拍板不留在对话里——后续清点、研究、brief 都要以这份落盘为共同参照。

## 输入 / 怎么做

输入：`认知地图集/diff/diff.md` 六段（尤其拍板候选）。

1. 人勾选拍板表：每条取一个取向（如 A/B/C/A+B），编码压缩成一行（如 `1=A 2=A 3=A+B …`）。
2. 主会话登记两件：`清点/00-拍板表.md`（逐条 + 编码 + 可推翻说明）+ `清点/主线.md`（主线压缩）。
3. 更新 `认知地图集/README.md` 状态行（本夹索引惯例）。
4. **人闸：拍板齐了才允许进 09 清点；不回探索、不再索取。**

## 边界

- 拍板 = 工作假设，不是死锁：研究用数据推翻时，账记 `_研究日志.md`（原判断/证据/新方向），**不回改拍板措辞**。
- 禁：探索线回头（第 3 轮索取、改地图）；为维护拍板强行解释后续数据。
- 曾错走法：主会话代拍板 → 废止；判断责任归人。
