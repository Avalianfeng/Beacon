# 11 · brief：方向手柄

> **第三幕。** 总图：[00-正式闭环](00-正式闭环.md)。  
> 在研究会话「做明白了」之后压缩，不是研究开始时的任务单。

## 谁 / 产物 / 人闸

| | |
|---|---|
| 谁 | 研究者可直写；主会话 `brief check`；人认红线与分级假设 |
| 产物 | `problems/<题>/brief.json` |
| 人闸 | 只压缩**已经用数据验证过**的方向 |

## 它在闭环里干什么

启动 Beacon 之后，brief 切片进各节点（执行约束、红线、各问方向、写作要点）。  
这是**驾驭图**的手柄，**不是**蓝图/模型卡：图内 critic 还要一份 `plan.json`（下一幕 `plan build`）。

证伪时二选一（研究者自己判断）：补 brief 再跑，或承认体系侧方向更好并记账。改 brief 后若已经 `run --plan` 过，必须**新开** run，不能 restart。

## 怎么做

1. 从 `解题说明` / `brief草稿` / 研究日志倒推机器可读字段。  
2. `math-agent brief check`。  
3. 不要在对撞/研究还没发生时用 brief 驱动它们。
