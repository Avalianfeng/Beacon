## 登记是什么（只记这一句）

给本地 agent 一个插入 Beacon 的插座。体系去跑这份代码；critic 不过就手改，再 `--force` 登记。  
**不是**把旧求解交进去交差，也不是替代 LangGraph。替代的是 coder 节点 LLM。

## 怎么做

```text
reference add   （或 source/inject/）
reference run   → evidence.json
verify / recertify
```

可以、也应该多次发生。每次登记服务的是**下一轮图内执行**。
