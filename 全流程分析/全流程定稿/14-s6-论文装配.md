# 14 · 启动图，写作在 writer

> **第四幕后半。** 总图：[00-正式闭环](00-正式闭环.md)。

## 谁 / 产物 / 人闸

| | |
|---|---|
| 谁 | 主会话驱动 LangGraph **写作与评审段**；coder LLM 默认关 |
| 产物 | writer 链产出的完整初稿（分节 checkpoint） |
| 人闸 | 禁造数；禁把骨架当论文 |

## 正式路径（已产品化）

```text
math-agent run ^
  --problem problems/<题>/problem.json ^
  --brief problems/<题>/brief.json ^
  --from writer ^
  --evidence runs/<题>-reference/evidence.json ^
  --out runs/<题>-writer-graph
```

可选 `--model-card path.json` 覆盖默认最小模型卡（assumptions / ModelVersion / blueprint / sensitivity）。

内部：`build_writer_state`（q_lines→primary stdout）→ `update_state(as_node=figure_analysis)` → `writer` → `writer_section*` → `paper_critic` → …

论文从这里出。`reference paper` 骨架、`expand`、会话手写 prose，都不是正式终态。

门禁停机后：

```text
math-agent restart --out runs/<题>-writer-graph --from writer --reason "…"
```
