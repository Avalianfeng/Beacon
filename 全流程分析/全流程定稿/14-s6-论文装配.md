# 14 · 启动图，写作在 writer

> **第四幕后半。** 总图：[00-正式闭环](00-正式闭环.md)。

## 谁 / 产物 / 人闸

| | |
|---|---|
| 谁 | 主会话驱动 LangGraph **全图**（`--plan` 注入上游产出位）；coder LLM 默认关 |
| 产物 | writer 链产出的完整初稿（分节 checkpoint） |
| 人闸 | 禁造数；禁把骨架当论文 |

## 正式路径

```text
math-agent run ^
  --problem problems/<题>/problem.json ^
  --brief problems/<题>/brief.json ^
  --plan problems/<题>/plan.json ^
  --out runs/<题>-graph
```

内部：播种 `as_node=analyst`（蓝图+final 模型卡，`plan_injected`）→ `blueprint_critic` / `model_critic` 真跑 → coder 执行冻结脚本 → 一致性 → 敏感性（须 `source/inject/sensitivity.py`）→ figure → writer ×7 → paper_critic。

论文数字只来自图内 `coder_execute` stdout。`reference run` 的 evidence 给人闸和 `review-check --strict`。

`--from writer` 仍可用作**应急接桥**（吃 evidence，会在 paper_critic 因缺两张证明而停机，按 [15](15-s7-评审.md) 人接管）。

论文从 writer 链出。`reference paper` 骨架、`expand`、会话手写 prose，都不是正式终态。

门禁停机后按交棒包：改代码则 `reference add --force` + `restart --from coder`；改 plan 则新开 run。
