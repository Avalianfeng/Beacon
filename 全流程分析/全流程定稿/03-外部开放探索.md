# 03 · 外部开放探索（第二家模型的独立头脑）

> **第一幕 · 外部探索线 1/3。** 总图：[00](00-正式闭环.md) ③ → 下一站 [04-索取与回填](04-索取与回填.md)。  
> 理解面：[讲解 §2](../讲解-一篇读懂Beacon闭环.md)（独立视角防锚定；两线互不偷看）。

## 这一段在防什么

一个头脑一个思路。本地自己的探索再努力，也可能整个团队锚定在同一条错误路径上。外部第二家（另一家模型）的价值是**另一个独立的先验**：它没看过你的研究、没被你带偏，能提出你没想到的知识与方向。

但独立的前提是**不对称**：它只读你打包给的题面/EDA/事实包，**不读你本机未公开的材料**（研究、地图、判断）——否则"独立"变成"共谋"。这条信息边界是本站的机制核心，不是礼貌。

## 输入 / 怎么做

输入：上一站的 `data_profile.md` + `eda/*.png`（打包给外部用的公开面）。

1. 主会话拼**事实包**（题面 + 画像 + 数据声明），人跑第二家：上传概览图 + 粘贴 [prompts/外部/模板-提示词0.md](../prompts/外部/模板-提示词0.md) + 本题事实包 + 索取协议要点。
2. 第二家输出 → **落盘**：`认知地图集/外部/轮次/轮N-原文.md`（须含判断，不是闲聊记录——"人把材料存成文件，不贴对话框当唯一真相"）。
3. 输出里带【索取】→ 进 [04-索取与回填](04-索取与回填.md)（本机算切片回填）；**先不要发 0.5**（闭环提示词留到地图阶段）。
4. 判断已够 → 直接进 [05-外部地图闭环](05-外部地图闭环.md)。

操作细则：`prompts/外部/操作-怎么发给第二家.md` · 事实包怎么写：`prompts/外部/说明-怎么写事实包.md`

## 边界

- 给外部的包**只含公开面**；禁带：研究判断、本地地图、拍板倾向、他题材料。
- 外部不联网搜本题题解当依据（提示词里禁）；它给的是知识/方法探索，不是终解。
- 人闸：原文落盘且含判断；对话轮次原文没落盘 = 这轮白跑（cumcm23-c 首轮就吃过这个亏）。

## 站终态树

```text
problems/<题>/认知地图集/外部/
  轮次/轮N-原文.md     ← 每轮外部原文（含判断）——外部探索的原始档案
  外发归档/            ← 发出去的打包件（含你给了它什么）
  索取/                ← 回填计算产物（下一站）
  地图/                ← 最终认知地图（再下一站）
```

| 资产 | 谁写 | 谁读 | 何时 |
|---|---|---|---|
| `轮次/轮N-原文.md` | 人贴回落盘 | Diff（07）对撞时读 | 每轮后立刻，不留对话框 |
| `外发归档/*` | 主会话打包 | 对账"我们到底给过什么" | 每次外发后 |
