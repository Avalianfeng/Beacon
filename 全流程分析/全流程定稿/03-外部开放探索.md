# 03 · 外部开放探索（第二家模型的独立头脑）

> **第一幕 · 外部探索线 1/3。** 总图：[00](00-正式闭环.md) ③ → 下一站 [04-索取与回填](04-索取与回填.md)。  
> 理解面：[讲解 §2](../讲解-一篇读懂Beacon闭环.md)（独立视角防锚定；两线互不偷看）。  
> **多视角**：外部与本地一样用 `V1/V2/…`——[说明-多视角版本.md](../prompts/外部/说明-多视角版本.md)（学-36）。

## 这一段在防什么

一个头脑一个思路。本地自己的探索再努力，也可能整个团队锚定在同一条错误路径上。外部第二家（另一家模型）的价值是**另一个独立的先验**：它没看过你的研究、没被你带偏，能提出你没想到的知识与方向。

但「一个外部」仍可能不够：同一家模型、同一次读图，照样会收成窄走廊。因此外部线**刻意版本化**——每个 `V*` 是独立视角（不同模型，或同模型不同视角标签），互不喂地图；Diff 吃的是「本地 + 多份已闭环外部图」，不是唯一外声。

独立的前提是**不对称**：它只读你打包给的题面/EDA/事实包，**不读你本机未公开的材料**（研究、本地地图、其他 `V*` 地图）——否则「独立」变成「共谋」。

## 输入 / 怎么做

输入：`data_profile.md` + `eda/*.png` + **`eda/图说.md`**（图说压缩进读图任务）。

0. 未建外部骨架先脚手架（默认仅 V1；要多视角再加 `--versions V2`）：  
   `python scripts/scaffold_external_maps.py --problem problems/<题>`
1. 主会话拼**事实包** → `source/方向生产-提示词包.md`（[说明-怎么写事实包.md](../prompts/外部/说明-怎么写事实包.md) · [说明-怎么写读图任务.md](../prompts/外部/说明-怎么写读图任务.md)）。
2. 在 `认知地图集/外部/README.md` **登记 V1**（模型 / 视角标签 / 状态）；工作区用 `外部/V1/`。
3. 人跑该视角：上传最多两张拼图 + [模板-提示词0.md](../prompts/外部/模板-提示词0.md) + 事实包 + 索取协议。  
   操作：[操作-怎么发给第二家.md](../prompts/外部/操作-怎么发给第二家.md)。
4. 原文落盘：`外部/V1/轮次/轮N-原文.md`（须含判断）。
5. 有【索取】→ [04](04-索取与回填.md)；判断够 → [05](05-外部地图闭环.md)（仍在本 V）。
6. **探索空间**：V1 闭环后（或并行新对话）按多视角说明的触发条件开 **V2**——新对话、新标签或新模型，**禁止粘贴 V1 地图**。

## 边界

- 给外部的包只含公开面；禁带：研究判断、本地地图、其他 V 的地图/轮次、拍板倾向、他题材料。
- 外部不联网搜本题题解；给的是知识/方法探索，不是终解。
- 读图任务回溯 `eda/图说.md`；「不要读成」须进外发。
- 人闸：原文落盘且含判断；没落盘 = 白跑。
- **不把「V1 已开」当成外部线结束**；Diff 前应审视是否还缺第二视角。
