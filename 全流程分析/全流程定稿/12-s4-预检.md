## 一句话

机械检查题面/附件/brief/路径是否齐，不烧求解、不调 LLM。

```text
uv run math-agent run --dry-run --problem problems/<题>/problem.json --brief problems/<题>/brief.json
```

`--dry-run` 不能和 `--plan` 同用。plan 的零 token 预检是下一站的 `plan check`。
