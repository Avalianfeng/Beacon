# 10 · 研究会话（把方向交给真实数据检验）

> **第二幕。** 总图：[00](00-正式闭环.md) ⑥ → 上一站 [07-Diff综合](07-Diff综合.md)（续跑源）→ 下一站 [11-brief定稿](11-brief定稿.md)。  
> 理解面：[讲解 §2 末](../讲解-一篇读懂Beacon闭环.md)（算完 ≠ 结束）。  
> 提示词：`prompts/研究/` · 出口契约：`prompts/研究/契约-研究出口.md` · 本题 `_派发/研究.md`

## 这一段在防什么

拍板只是"想出来的方向"，还没有被真实数据检验过——拍板表自己也常标着"未验"项。研究段把方向拿到真实数据上跑：回测、实验、否证、修正，直到形成**经真实计算检验的稳定认识**。两个方向性防错：

- **别为维护拍板而解释数据**：拍板是工作假设，实验可以推翻，推翻必须记账（原判断 → 证据 → 结果 → 新方向）。
- **别把研究当交付**：算完只是"你信任自己"；论文要的是别人能复核——所以研究收束 = 把认识**外显**（日志/说明/经验/brief 草稿 + 资产），"自己跑完 ≠ 结束"。

## 输入 / 怎么做

输入：diff/拍板/清点 + 题根数据 + 研究资产（可读工作区全部题内材料，禁读外部地图与他题/题解）。

1. **优先在 Diff 对话续跑**（方向认知还热着，不要硬切"求解 Agent"）；新开会话也行——事实从工作区重读，不依赖聊天记忆。
2. 把题算明白：读数据/实验/局部建模/否证/修正；允许子 Agent 独立验证或分叉探索。
3. 持续写 `_研究日志.md`（问题→做了什么→结果→认识变化→下一步），重要推翻必记。
4. 边际收益低于成本时**收束**，压缩交付（详见出口契约）：`_研究日志` / `解题说明` / `经验与坑` / `exploration.md`（人读收束）/ `brief草稿` + `研究/{scripts,data,figures}/`。
5. 敏感性表只**定网格与参数名**——论文敏感性数字之后由图内重跑（14），研究表不是论文数字源。

人闸：不按文件清单卡死；看是否已形成"够稳、有证据"的解题认识。

## 边界

- 禁：联网搜本题题解当依据；读他题研究；把研究敏感数字直接当论文事实。
- 敏感性口径允许与拍板不同——用数据说话，账记日志。

## 站终态树

problems/<题>/
