# 06 · 本地认知地图（自己的独立证据）

> **第一幕 · 本地探索线。** 总图：[00](00-正式闭环.md) ③ → 下一站 [07-Diff综合](07-Diff综合.md)。  
> 理解面：[讲解 §2](../讲解-一篇读懂Beacon闭环.md)（一个头脑不够 → 干净会话长探索）。  
> 提示词：`prompts/本地/` · 本题 `_派发/本地.md`

## 这一段在防什么

外部地图再好也是别人的先验。对撞之前，本地必须有**自己的独立证据**——否则 Diff 变成"听外部说"，而不是"两个独立头脑撞出来"。本地探索由主会话派**一个干净上下文的子 agent**完成：它只读题面与数据公开面，产出一份不带外部影响的事实视图 + 认知视图。

形式约束（学-16）：**一次长探索、两个视图**——不是 hop1→人审→hop2 的短跳接力，也不是两个模型互聊。证据卡 = 事实视图（数据里有什么）；认知地图 = 认知视图（可能意味着什么、含可推翻项）。

## 输入 / 怎么做

输入：题面、`source/`、`eda/`（含 PNG 与 **`eda/图说.md`**）、`data_profile`、`外部/_共享/切片`（可复用事实；**不**读 `V*/索取` 叙事）。

**默认时机**：外部 V1 至少已开跑一轮探索后再派（有无索取均可）；有共享切片则可读。不必等 V1 地图闭环，也不必等 V2。

1. 主会话把本题 `_派发/本地.md`（或 prompts/本地/模板-派发.md）贴给一个干净子 agent。
2. 子 agent 在**探索工作区根上**产出：`_证据卡.md` + `认知地图-本地.md`（可自管 scripts/data/figures）。
3. 主会话抽查：证据卡里的数字能对齐、地图含可推翻项；图说里的缺口未被当成「表里有销量」之类。
4. 通过 → 本地线收口，进 07 Diff。

信息边界（这是本站机制的核心）：
- 可读：题面、`source/`、`eda/`（含图说）、`data_profile`、`外部/_共享/切片`（事实；可读 `_索引.md`）
- 禁读：`外部/V*/地图|轮次|外发归档|索取`（**所有**外部视角的完整档案）、他题、联网题解
- 图说用途：理解「图想让人看见什么 / 不负责什么 / 列缺口」；**不是** brief，不是求解定案
- 与外部对等：本地也用 `V1/V2/…`；产新 V 时禁把旧 V 结论当依据（学-16）；外部多视角见学-36

## 边界

- 禁：本地看**任何**外部 V 的地图/轮次/外发/**索取档案**（互锁）；产新本地 V 时读旧版结论当依据。`_共享/切片` 可读。
- 人闸：抽查通过才可 Diff。
- 曾错走法：两跳派发（hop1→审→hop2）→ 废止，一次长探索两视图（学-16）。
