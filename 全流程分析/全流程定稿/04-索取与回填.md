# 04 · 索取与回填（缺证据就补算，封顶不恋战）

> **第一幕 · 外部探索线 2/3。** 总图：[00](00-正式闭环.md) ③ → 上一站 [03](03-外部开放探索.md) → 下一站 [05](05-外部地图闭环.md)。  
> 协议：`prompts/外部/协议-索取.md` · 多视角：`说明-多视角版本.md` · **索取分家**：`说明-索取目录契约.md`（学-37）

## 这一段在防什么

第二家说「缺证据」时有两种可能：真缺或偷懒/试探。正确姿势：**本机先算，算完打包回填**。

另防 **cumcm23 式混放**：轮次、脚本、可复用表、发送现场全堆进一个 `外部/索取/`——看起来编号整齐，实则无法回答「谁要的、哪一轮、能否给另一视角复用」。因此：

- **可复用**切片与算子 → `外部/_共享/`  
- **该视角完整索取档案** → `外部/V*/索取/`  
- **打包**只对着 `V*/索取/轮N/`，打完进 `V*/外发归档/`

| 层 | 含义 | 做不做 |
|---|---|---|
| **A 口径** | 看不见会拍错板 | 做；**每个 V** 最多 2 轮、每轮 ≤8 条；第 2 轮 = 该视角最后补全 |
| **B 试探建模** | 弹性/整表优化试跑 | 默认不做；记「研究阶段待算」（10） |

## 输入 / 怎么做

输入：当前 `V*` 原文【索取】+ 题根数据。

1. 查 `外部/_共享/切片/_索引.md`：同口径则复用 ID；否则新算。  
2. 新产物：写入 `_共享/切片/` 并登记索引；通用算子进 `_共享/scripts/`。  
3. 在 **`V*/索取/轮N/清单.md`** 记下条目 ↔ 共享 ID / 本目录文件 ↔ 用途。  
4. 更新 `V*/索取/README.md` 总账。  
5. 打包（解析 `_共享`，成品进外发归档）：  
   `python scripts/pack_external_upload.py --dir problems/<题>/认知地图集/外部/V*/索取/轮N --stem 给第二家-V*-轮N --resolve-shared`  
6. 贴回（含判断）→ `V*/轮次/`。

人闸：该视角够了 → 05；拍板后不回探索；仍可开新 V。

## 边界

- 禁止用 `_共享/` 整夹或「历史大索取锅」当 pack 目录。  
- 禁止把 V1 `索取/` 整夹拷进 V2 冒充复用（复用走索引 ID）。  
- 同一 V 无第 3 轮 A；新 V 重计 2 轮。
- 新题脚手架：`python scripts/scaffold_external_maps.py --problem problems/<题>`（默认仅 V1）。

## 站终态树

```text
problems/<题>/认知地图集/外部/
  _共享/
    scripts/                 ← 可复用算子 + README
    切片/ + _索引.md         ← 可复用产物与复用账
  V*/索取/
    README.md                ← 本 V 索取总账
    轮N/清单.md + 发送文件   ← 完整现场（pack 源）
    scripts/                 ← 可选：本 V 编排
  V*/外发归档/               ← 打包成品
  V*/轮次/                   ← 贴回原文
```

| 资产 | 谁写 | 谁读 | 何时 |
|---|---|---|---|
| `_共享/切片`+索引 | 主会话 | 各 V 回填；本地探索可读切片 | 首次产出时 |
| `V*/索取/**` | 主会话 | 主持/该 V 打包；**默认本地不读** | 每轮索取 |
| `V*/外发归档/*` | 主会话 | 对账该视角发出过什么 | 每次外发后 |
