# 04 · 索取与回填（缺证据就补算，封顶不恋战）

> **第一幕 · 外部探索线 2/3。** 总图：[00](00-正式闭环.md) ③ → 上一站 [03-外部开放探索](03-外部开放探索.md) → 下一站 [05-外部地图闭环](05-外部地图闭环.md)。  
> 协议：`prompts/外部/协议-索取.md`

## 这一段在防什么

第二家说"缺证据"时有两种可能：真缺（看不见会拍错板）或它想偷懒/试探。空手对聊解决不了前者——没算过的口径答不了。所以索取的正确姿势是：**本机先算，算完打包回填**。

反方向的风险是探索无底洞：一家外部模型可以无限索取，每轮烧时间烧人。所以索取要**封顶分层**（下表是协议，不是 CLI 上限）：

| 层 | 含义 | 做不做 |
|---|---|---|
| **A 口径** | 看不见会拍错板的（量级、结构、对齐、口径） | 做；最多 **2 轮**、每轮 ≤8 条；第 2 轮 = 最后一次证据补全 |
| **B 试探建模** | 弹性拟合、整表优化试跑 | **默认不做**；记"研究阶段待算"（10），不在这里烧 |

## 输入 / 怎么做

输入：03 原文里的【索取】清单 + 题根数据。

1. 主会话算 A 条 → 写入 `外部/索取/`（编号表，能对上第几轮第几条）。
2. 打包：`python scripts/pack_external_upload.py --dir problems/<题>/认知地图集/外部/索取 --stem 给第二家-打包`
3. 打包件 + 交棒说明挪进 `外部/外发归档/`。
4. 第二家贴回**必须含**：判断 / 地图更新 / 最易漏点——只回数字不判断 = 没闭环。

人闸：人+主会话合判"够了吗"；够了才进 05，拍板后**不回探索**。

## 边界

- 第 3 轮 = 禁止（拍板后不回探索）；第 2 轮就是最后补全。
- 回填数字落盘在 `索取/`，不贴对话框当唯一真相。
