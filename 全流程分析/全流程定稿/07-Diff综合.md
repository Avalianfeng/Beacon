# 07 · Diff 综合（多个独立头脑撞出来的方向）

> **第一幕 · 人对撞。** 总图：[00](00-正式闭环.md) ④ → 下一站 [08-拍板登记](08-拍板登记.md)。  
> 理解面：[讲解 §2](../讲解-一篇读懂Beacon闭环.md)（判断责任归人）。  
> 提示词：`prompts/diff/模板-派发.md` · 出口契约：`prompts/diff/契约-综合出口.md` · 本题 `_派发/diff.md`  
> 外部多视角：`prompts/外部/说明-多视角版本.md`（学-36）

## 这一段在防什么

多线探索各自独立，为的就是此刻的**对撞**：共同点是什么、冲突在哪（口径/证据/解释/方法）、能不能结合。若让写地图的会话自己裁决，它各有立场；若让主会话代写，它没有参与探索的上下文。Diff 必须是**人新开的干净对话**——只读题面/数据，先锁预构想，再读地图，最后综合。

外部若有多个已闭环 `V*`，Diff 吃的是**本地现行版 + 全部外部闭环地图**——刻意保留三角/多角冲突，而不是先人工合成一张「官方外图」再对撞（那会吞掉探索空间）。

**硬顺序（防锚定，仅 Diff 段有效）**：

```text
只读题面/数据 → 锁存 _预构想.md → 才读：本地现行地图 + 所有已闭环 外部/V*/地图
→ 比较/综合/验证 → diff.md（六段）
```

先写预构想再读图，是为了让「我本来的想法」先落盘，读图时能看见自己被撞偏了多少——否则容易读图即从众。

## 输入 / 怎么做

输入：全部已闭环外部地图（05）+ 本地现行地图（06）+ 题面/数据 + 可用小脚本验证方向。

1. 人新开干净对话，粘贴本题 `_派发/diff.md`（或 prompts/diff/模板-派发.md）。
2. 按硬顺序产出 `diff/_预构想.md` → `diff/diff.md`，六段齐：
   预构想摘要 / 共同 / 冲突（口径·证据·解释·方法，**标注来源：本地 / 外部-V1 / 外部-V2…**）/ 结合机会 / 验证结果 / **拍板 ≤8 条 + 可推翻**。
3. 可用代码验证结合方向（如小回测），但**此段不闭合成进货表/最优种植表**——那是研究段的事。
4. 若只有一个外部 V：仍可 Diff，但建议在拍板备注「未开第二外部视角」为可选债（探索空间未用满）。

人闸：主会话抽查六段齐、且「当时」没滑成完整竞赛解；抽查通过才进拍板。

## 边界

- Diff 不是独立职业：人拍板后**同一对话可续跑**进 [10-研究会话](10-研究会话.md)（学-21）；要换新会话也可，事实从工作区重读。
- 不要为维护 diff 措辞而强行解释后续数据。
- 不要在 Diff 前把多份外部地图揉成一份「主持摘要外图」再只读摘要——除非人明确要求，且原 V 地图仍保留可溯源。
- 曾错走法：主会话手写 diff 表 → 废止；「Diff 后必须另开求解 Agent」→ 学-21 废止（可续跑）。
