# 07 · Diff 综合（两个独立头脑撞出来的方向）

> **第一幕 · 人对撞。** 总图：[00](00-正式闭环.md) ④ → 下一站 [08-拍板登记](08-拍板登记.md)。  
> 理解面：[讲解 §2](../讲解-一篇读懂Beacon闭环.md)（判断责任归人）。  
> 提示词：`prompts/diff/模板-派发.md` · 出口契约：`prompts/diff/契约-综合出口.md` · 本题 `_派发/diff.md`

## 这一段在防什么

两线探索各自独立，为的就是此刻的**对撞**：共同点是什么、冲突在哪（口径/证据/解释/方法）、能不能结合。若让写地图的会话自己裁决，它各有立场；若让主会话代写，它没有参与探索的上下文。Diff 必须是**人新开的干净对话**——只读题面/数据，先锁预构想，再读双图，最后综合。

**硬顺序（防锚定，仅 Diff 段有效）**：

```text
只读题面/数据 → 锁存 _预构想.md → 才读外部地图+本地地图
→ 比较/综合/验证 → diff.md（六段）
```

先写预构想再读双图，是为了让"我本来的想法"先落盘，读图时能看见自己被撞偏了多少——否则容易读图即从众。

## 输入 / 怎么做

输入：外部地图（05）+ 本地地图（06）+ 题面/数据 + 可用小脚本验证方向。

1. 人新开干净对话，粘贴本题 `_派发/diff.md`（或 prompts/diff/模板-派发.md）。
2. 按硬顺序产出 `diff/_预构想.md` → `diff/diff.md`，六段齐：
   预构想摘要 / 共同 / 冲突（口径·证据·解释·方法）/ 结合机会 / 验证结果 / **拍板 ≤8 条 + 可推翻**。
3. 可用代码验证结合方向（如小回测），但**此段不闭合成进货表/最优价**——那是研究段的事。

人闸：主会话抽查六段齐、且"当时"没滑成完整竞赛解；抽查通过才进拍板。

## 边界

- Diff 不是独立职业：人拍板后**同一对话可续跑**进 [10-研究会话](10-研究会话.md)（学-21）；要换新会话也可，事实从工作区重读。
- 不要为维护 diff 措辞而强行解释后续数据。
- 曾错走法：主会话手写 diff 表 → 废止；"Diff 后必须另开求解 Agent" → 学-21 废止（可续跑）。

## 站终态树

```text
problems/<题>/认知地图集/diff/
  README.md      ← 状态与读法
  _预构想.md      ← 读双图前锁存的本能方向（防锚定的对照点）

  scripts/ data/ figures/   ← 验证结合方向的小实验
```
