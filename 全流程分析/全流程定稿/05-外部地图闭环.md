# 05 · 外部地图闭环（探索的终点是一张地图）

> **第一幕 · 外部探索线 3/3。** 总图：[00](00-正式闭环.md) ③ → 上一站 [04-索取与回填](04-索取与回填.md) → 下一站 [06-本地认知地图](06-本地认知地图.md)。  
> 提示词：`prompts/外部/模板-提示词0.5-闭环.md`

## 这一段在防什么

探索聊得再多，如果终点是一堆对话记录，对撞时无法使用。这一站强制外部把它的理解收束成**一张认知地图**（哪些方向可行、哪些口径有坑、哪些它不确定），而不是继续索取、继续闲聊。0.5 提示词因此是**闭环专用**——它不是"开放续聊"，是"把你知道的写成图"。

## 输入 / 怎么做

输入：03/04 的回合产物（原文 + 回填 + 它自己的更新）。

1. 打包件开头带**交棒说明**：你要了什么 / 我们给了什么 / 现在走到哪 / 请执行 0.5-闭环提示词。
2. 第二家出**认知地图**（不是继续索取）。
3. 主会话确认落盘：`认知地图集/外部/地图/认知地图-<标记>.md`。
4. 产本地地图期间（06），外部地图**禁读**——对撞公平靠这条互锁，别提前看。

## 边界

- 禁：0.5 用于续聊；地图产出前再开索取轮。
- 人闸：地图进 `地图/` 且含可对撞的判断；此后不再索取（拍板后不回探索）。
- 曾错走法："提示词 0.5 开放续聊" → 已改为闭环专用（学-13/15）。
