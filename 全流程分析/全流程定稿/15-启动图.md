# 15 · 启动图（run --plan：注入 + 真检的自然全图）

> **第四幕 · 正式入口。** 总图：[00](00-正式闭环.md) ⑩ → 上一站 [14-plan与登记](14-plan与登记.md) → 下一站 [16-停机交棒](16-停机交棒.md)。  
> 理解面：[讲解 §3.2–§3.7](../讲解-一篇读懂Beacon闭环.md)（注入+真检；敏感性重跑；writer 唯一出处）。

## 这一段在防什么

这是接洽的完成式：图**不拦腰截断**（不从 writer 冷启）、**不自由生成**（不让 LLM 重想），而是把 plan 播种到 analyst/modeler 产出位后，让图内自己的 critic **真跑检验**——研究结论以图能审的形态过图自己的门，这就是"接入的正当性"。之后按原边自然流到 coder（执行登记代码）→ 一致性 → 敏感性（重跑 inject）→ figure → writer → 评审。

**正式入口只有 `run --plan`**。`--from writer` 是应急接桥（会因缺上游证明在论文评审门结构性停机），正式题不要拿它当第一枪。

## 输入 / 怎么做

输入：`problem.json` + `brief.json` + `plan.json` + 登记好的 `_entry`/inject（14 站产物）。

```text
uv run math-agent run ^
  --problem problems/<题>/problem.json ^
  --brief problems/<题>/brief.json ^
  --plan problems/<题>/plan.json ^
  --out runs/<题>-graph
```

第一枪 `--out` 用 `runs/<题>-graph`；改 plan/brief 后**新开**目录（如 `runs/<题>-graph-r2`），不要指望 `restart` 吸收输入戳变化。

互斥：`--plan` 不能与 `--from writer` / `--dry-run` / `--allow-coder-llm` 同用；必须带 `--brief`。
无人值守加 `--no-interrupt`（跳过 human_review = 自动批准）——**要人看稿就不要加**；加了也不等于人验收（17 站）。

图内顺序（图结构不改，靠 `plan_injected` 短路生成）：

```text
播种 as_node=analyst（蓝图 + final 模型卡 + stage=final）
  → blueprint_critic 真跑          ← 不过：edit_plan，新开 run
  → modeler（有 final 卡则 0ms 短路，推导链全跳）
  → model_critic 真跑              ← 不过：edit_plan，新开 run
  → coder：执行冻结 _entry（哈希校验，零 LLM）
  → model_code_consistency         ← 不过：edit_code
  → 敏感性：LLM 出计划 → 执行 inject/sensitivity.py（缺/失败 = 停机）
  → figure → writer × N 节（每节 checkpoint）→ paper_critic
  → table → evaluation → 人审 → latex → finalizer
```

**论文数字只来自图内 stdout**（主结果 = coder_execute；敏感性 = inject RESULT）。`reference run` 的 evidence 只给人闸与 `--strict` 对账。

## 边界

- 禁：首枪 `--from writer`；改 plan/brief 后 restart（输入戳会拒 → 新开 `--out`）。
- 停机 = 交棒点，不是失败：读 `runs/<id>/critic-handoff.md`，按 [16-停机交棒](16-停机交棒.md) 动作。
- 首跑常见坑（血缘/无主证据/敏感性停/plan 空字段）→ 00 [第 8 节](00-正式闭环.md)。这些是**图内/登记**问题，与第一幕外部多 V / 索取**无关**——不要因此重开外部探索。

## 站终态树

```text
runs/<题>-graph/
  paper.md            ← writer 链产出（分节 checkpoint 后）
  critic-handoff.md/.json   ← 停机时自动写（有停点才有）
  completion.json     ← finalizer 钉账（completed / degraded）
  checkpoints.sqlite  ← 节点级存档（restart/recover 的依据）
```
