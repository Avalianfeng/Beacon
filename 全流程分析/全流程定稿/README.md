## 怎么读

1. 用 Beacon 之前：读 00（角色、五幕、第四/五幕命令）。  
2. 做到某一段：打开对应文件。  
3. 正式启动图只认 `run --plan`。`--from writer` 是应急，不要当第一枪。  
4. 不要从 docs/adr、操作面「S9 可选」、或 archive 学习走查反推现行用法。
