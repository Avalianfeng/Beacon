# 全流程定稿

> **做题与用法的唯一操作权威。** 先读 [00-正式闭环.md](00-正式闭环.md)（总图 + 命令 + 数字口径）。  
> **理解面**（为什么长这样）在 [讲解-一篇读懂Beacon闭环.md](../讲解-一篇读懂Beacon闭环.md)——每站开头链回讲解对应小节。  
> 01–17 是各段怎么做；和 00 冲突时信 00。提示词在 [`../prompts/`](../prompts/README.md)。旧稿在 [`../archive/`](../archive/README.md)。

## 怎么读

1. 用 Beacon 之前：读 00（角色、五幕）+ 讲解（理解面，一遍即可）。
2. 接手/续跑某题：先读 `problems/<题>/进行状态.md`（探索期活状态页；会话首读末写；⑨ 收束并入 `交接-beacon.md`）。
3. 做到某一段：打开对应站文件（结构统一：防线 / 输入 / 怎么做 / 边界 / 站终态树 / 自查 / 本题状态）。
4. 正式启动图只认 `run --plan`；`--from writer` 是应急，不要当第一枪。
5. 不要从 docs/adr、操作面「S9 可选」、或 archive 学习走查反推现行用法。
6. 真跑教训（坑/案例/设计债）在 [`../图内真跑/`](../图内真跑/README.md)——不是用法，卡住时查。
