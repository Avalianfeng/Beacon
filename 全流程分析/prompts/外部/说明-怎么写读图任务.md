# 说明 · 怎么写读图任务（新题临时生成）

> 02 EDA 画像约定：定稿 [02-EDA画像](../../全流程定稿/02-EDA画像.md) · [`../eda/`](../eda/)。  
> **唯一上游**：本题 `eda/图说.md`。禁止另起一套「画了什么」，禁止写「按惯例每附件一图」。

## 产出物

在本题事实包（常为 `source/方向生产-提示词包.md`）里写一节 **「读图任务」**，含：

1. **上传策略**（人发给第二家时照做）  
2. **读图表**（有图模型按图；无图模型靠「图说了什么」）  
3. **图说了什么**（无图像底线描述）  
4. **明确不要读成什么**（从图说「不负责呈现 / 缺口」抄过来）

## 上传策略（默认）

外部模型常有「一次几个文件」上限。不要把 `eda/` 下所有 PNG 逐张塞满：

| 优先级 | 上传什么 | 说明 |
|---|---|---|
| P0 | 最多 **两张拼图** | 例：`概览三合一.png`（骨架）+ `概览补图.png`（特征补丁） |
| P1 | 图说里标「必须单图细读」的 0–2 张原图 | 仅当拼图糊掉关键标注时 |
| 文字 | 提示词 0 + 事实包全文 | 始终粘贴 |

拼图命令示例（按本题实际 glob，不要死抄「四合一」）：

```text
# 骨架：附件编号图（若仍用 附件*.png 命名）
python scripts/pack_external_upload.py --dir problems/<题>/eda --glob-png "附件*.png" --stem 概览三合一 --md-skip

# 特征补丁：图说 §3 / 补-* 系列
python scripts/pack_external_upload.py --dir problems/<题>/eda --glob-png "补-*.png" --stem 概览补图 --md-skip
```

若本题没有「附件* / 补-*」前缀，按图说 §1 文件名显式列 `--glob-png`，或手工挑选后再拼。

## 读图表格式

每张**实际上传**的图（或拼图里可辨认的子图）一行：

| 图（文件名） | 要看见的特征（不是图型名） | 对撞时请回答 | 不要读成 |
|---|---|---|---|

规则：

- 「要看见的特征」从图说 §1「想呈现的特征」抄/压，勿改写成方法名。
- 「对撞时请回答」写成开放问题，服务淘汰方法或提出拍板点。
- 「不要读成」必须带：空模板≠已有解；缺口列≠用别的量冒充；利用率二值≠「还有空地」之类易错读（按本题图说填）。

## 图说了什么

无图像模型的底线：每张上传图 2–4 句结构描述（量级、构成、对齐、缺口）。有图则以图为准；冲突时第二家应标出冲突。

## 原则

- 图是共享视觉证据，不是论文图。
- 对撞时每张上传图至少用一次（淘汰或拍板），不要只重复文字统计。
- 张数服从特征，不服从附件编号。
