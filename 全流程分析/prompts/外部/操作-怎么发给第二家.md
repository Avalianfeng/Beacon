# 怎么发给第二家（可复用操作）

1. 把本题 `eda/` 下概览拼图作为**一张图**上传（可用 `scripts/pack_external_upload.py`）。能看图的模型请当图片上传。
2. 粘贴：`模板-提示词0.md` + 本题事实包（附件清单、读图任务、题面、聚合数字）+ `协议-索取.md` 要点。
3. 同一会话先不要急着发 0.5。若模型输出【索取】或判断：把**整段存成** `problems/<题>/认知地图集/外部/轮次/轮N-原文.md`（必须含判断 / 地图更新 / 最容易漏掉的东西）。不要只贴对话框。
4. 回填计算写入 `认知地图集/外部/索取/`；对外只上传打包件，打完挪进 `外部/外发归档/`。不要传分 csv。
5. **第 2 轮 A = 最后一次证据补全**，不是第二次开放探索。够了：打包件开头带交棒 + `模板-提示词0.5-闭环.md`，同一会话执行，不要第三轮索取。
6. 外部地图存到 `problems/<题>/认知地图集/外部/地图/`。禁止搜本题题解。产本地时禁读 `地图/`、`轮次/`、`外发归档/`。

不能上传图片时：开头声明无图像，按事实包里的「图说了什么」工作；看图才能判断的点写进判断，不要假装看见了图。
