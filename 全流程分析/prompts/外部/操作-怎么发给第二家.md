# 怎么发给第二家（可复用操作）

> 多视角：`说明-多视角版本.md` · 索取分家：`说明-索取目录契约.md` · 读图：`说明-怎么写读图任务.md`

## 开跑前

1. `外部/README.md` 登记 Vn（模型、视角标签、状态）。  
2. 工作区 = `外部/Vn/`（含 `索取/` `轮次/` `外发归档/` `地图/`）。  
3. 可复用层 = `外部/_共享/`（切片 + scripts + 索引）——**不是**打包根目录。

## 该视角 · 探索 / 索取

1. 上传最多两张拼图 + 提示词 0 + 事实包 + 索取协议。  
   **禁**粘其他 V 的地图/轮次/索取档案。  
2. 原文 → `Vn/轮次/轮N-原文.md`。  
3. 有【索取】：  
   - 查/写 `_共享/切片/_索引.md` 与 `_共享/scripts/`  
   - **完整档案**写在 `Vn/索取/`（总账 + `轮N/清单.md`；清单写切片 ID）  
   - pack（解析共享 → 成品进外发归档）：  
     `python scripts/pack_external_upload.py --dir …/外部/Vn/索取/轮N --stem 给第二家-Vn-轮N --resolve-shared`  
   - 不要把 `_共享/` 整夹当 `--dir`  
4. 第 2 轮 A 后 0.5-闭环 → `Vn/地图/认知地图.md`；更新 `外部/README`。

## 开 V2

需要时再脚手架：`python scripts/scaffold_external_maps.py --problem problems/<题> --versions V2`。  
新对话；标签/模型尽量不同；复用切片只经 `_共享` 索引；**禁止**把 V1 `索取/` 整夹拷过去或喂给模型。

## 产本地时

**默认时机**：外部 V1 至少跑过一轮探索（有或无索取均可）后再派本地；若已有 `_共享/切片`，本地可读事实切片。不必等 V1 地图闭环。  
可读：`_共享/切片`（事实）。  
禁读：所有 `V*/地图|轮次|外发归档|索取`。
