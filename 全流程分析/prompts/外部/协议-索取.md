# 索取协议（可复用）

事实包和概览图是第一批证据，不是全集。对撞中若某条判断依赖没看见的切片，**先索取、后下结论**。

每条单独一行：

```text
【索取】层=A|B  类型=图|统计|表切片|样例行|列释义  内容=<具体要什么>  用途=<对应哪一小问/哪条淘汰>
```

规则：

- **层 A = 口径**：看不见就会拍错板。本阶段只做 A。  
- **层 B = 试探建模**：标 `研究阶段待算`，本阶段不展开。  
- 一轮最多 **8** 条；**每个外部视角**最多 **2** 轮 A。  
- 回填落盘契约见 `说明-索取目录契约.md`：**可复用**进 `_共享/`，**完整索取档案**进 `V*/索取/`；禁止再堆成单一大锅 `外部/索取/`。  
- 要聚合，不要整表。拒绝：dump、本题题解、编造数字、把 B 当 A。  
- 够了写 `【索取】无`，进入 0.5-闭环。

贴回主持方必须带：**判断 / 地图更新 / 最容易漏掉的东西**，不能只有【索取】块。
