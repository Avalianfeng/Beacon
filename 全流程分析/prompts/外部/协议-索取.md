# 索取协议（可复用）

事实包和概览图是第一批证据，不是全集。对撞中若某条判断依赖没看见的切片，**先索取、后下结论**。

每条单独一行：

```text
【索取】层=A|B  类型=图|统计|表切片|样例行|列释义  内容=<具体要什么>  用途=<对应哪一小问/哪条淘汰>
```

规则：

- **层 A = 口径**：看不见就会拍错板（集合定义、可忽略性、双表是否同一量、窗口下降是构成还是掉 SKU 等）。本阶段只做 A。
- **层 B = 试探建模**：同 SKU 弹性、按候选模型把表跑一遍、完整优化输入。标 `S5 待算`，本阶段不展开。
- 一轮最多 **8** 条；方向生产阶段最多 **2 轮 A**。
- **第 2 轮 = 最后一次证据补全**：拿到第 1 轮回填后重新判断关键缺口，最多再要一次，然后进入 0.5-闭环。禁止把本地变成远程计算奴隶。
- 要聚合，不要整表。拒绝：dump、本题题解、编造数字、把 B 当 A。
- 够了写 `【索取】无`，进入提示词 0.5-闭环。

贴回主持方必须带：**判断 / 地图更新 / 最容易漏掉的东西**，不能只有【索取】块。
