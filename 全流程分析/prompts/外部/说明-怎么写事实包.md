# 说明 · 怎么写事实包（新题临时生成）

不要把死题面塞进可复用模板。新题在 `problems/<题>/source/方向生产-提示词包.md`（或等价填充件）写：

1. **附件清单**：文件名、角色、行数/规模、外部现在能看见什么 / 故意不给什么、列名原文、表里没有的字段。
2. **题面全文**（或与 `problem.md` 一致的摘录）。
3. **已读取的聚合数字**（与概览图配套，不是替代图）：目录规模、流水区间、退货/打折比例、成本对齐情况、损耗双表摘要。
4. **粗算锚点**（不是答案）：决策窗口、约束数字、量级提示。
5. **待裁决草稿**（人未拍板）：口径候选列表，标「待拍板」。

哈希与路径以 `source/manifest.json` 为准；事实包写给人读的摘要即可。
