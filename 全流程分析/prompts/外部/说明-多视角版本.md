# 说明 · 外部多视角版本（V1 / V2 / …）

> 对应定稿 03–05、07；学-36。  
> 索取如何分家（反混放）：**[说明-索取目录契约.md](说明-索取目录契约.md)**（学-37）——必读。  
> **目的**：外部线与本地线结构对等；刻意放大可对撞的探索空间。

## 1. 为什么要版本化

| 风险 | 单槽会怎样 | 多 `V*` 怎样挡 |
|---|---|---|
| 一家模型一条路 | Diff 只有「本地 vs 这一家」 | 再开 V2：另一模型 / 另一视角标签 |
| 重跑覆盖旧图 | 旧判断丢失 | V1 归档；V2 干净开跑 |
| 视角污染 | 顺着第一张地图改 | 禁喂其他 V 的地图/轮次/**索取叙事** |
| 过早收敛 | 「外部已闭环」停探索 | 闭环只表示该视角收口 |

## 2. 目录契约（新题默认）

```text
problems/<题>/认知地图集/外部/
  README.md
  _共享/                      ← 可复用：scripts + 切片 + _索引（不是大锅索取）
  V1/
    README.md                 ← 模型 / 视角标签 / 状态
    索取/                     ← 【完整】本视角索取档案（分轮清单 + 发送集）
    轮次/  外发归档/  地图/
  V2/ … 同构
```

| 路径 | 共享？ | 完整内容？ |
|---|---|---|
| `_共享/切片`+`scripts` | ✅ 可复用事实与算子 | 否——无「谁要的、哪一轮」叙事 |
| `V*/索取/` | ❌ | ✅ 该视角索取总账与发送现场 |
| `V*/轮次|外发归档|地图` | ❌ | ✅ 该视角对话、打包、闭环图 |

旧题 cumcm23 扁平 `外部/索取/` = 历史混放；新题禁止再堆成那样。

## 3. 视角怎么开（放大探索空间）

`V*/README.md` 开跑前四行（不准写本地结论）：模型 / 视角标签 / 事实包 / 状态。

视角标签鼓励多样：`方法族` · `约束可行` · `评委风险` · `不确定稳健` · `运营田间` …

**倾向开新 V**：另一模型；V1 过薄；与本地预构想零冲突；Diff 前仍缺轴。  
**不要开**：只改错别字；偷运本地结论。

## 4. 预算

| 项 | 规则 |
|---|---|
| 每 V 的 A 索取 | ≤2 轮、每轮 ≤8 条 |
| 题级 V 数 | 不硬封顶；Diff 前尽量 ≥2 闭环视角 |
| 切片复用 | 先查 `_共享/切片/_索引.md`；命中只记账，不复制第二套口径 |

## 5. 信息边界

| 角色 | 可读 | 禁读 |
|---|---|---|
| 外部 Vn | 题面、事实包、拼图、回填包、`_共享` 经回填可见的切片 | 其他 V 的地图/轮次/**索取档案**；本地地图 |
| 本地探索 | 题面、eda、图说、**`_共享/切片`** | 所有 `V*/地图|轮次|外发归档|索取` |
| Diff | 预构想后：全部已闭环 `V*/地图` + 本地现行；溯源可查 `_索引.md` | 未闭环当定案 |

## 6. Diff

本地现行 + 全部已闭环外部 V*；冲突标注 `本地` / `外部-V1` / `外部-V2` …  
仅一外部 V 时仍可 Diff，记「未开第二外部视角」为可选债。

## 7. 主持最短操作

1. 脚手架（若尚未）：`python scripts/scaffold_external_maps.py --problem problems/<题>`（默认仅 V1）  
2. 登记 V1 → 开跑 `外部/V1/`  
3. 索取：共享落 `_共享/` + 索引；清单写 ID；`pack … --resolve-shared` → `V1/外发归档/`  
4. 闭环 → `V1/地图/`  
5. 需要时再 `--versions V2`；新对话；复用走索引；不喂 V1 地图/索取叙事  
6. 本地：V1 开跑一轮后派；更新 `外部/README.md` 可对撞列表
