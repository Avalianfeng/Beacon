# 模板 · 提示词 0.5-闭环（索取够了 · 出地图）

可打进打包件一起发。第 2 轮 A 回填后默认用本模板，不要第三轮索取。

> 停止索取。已回填的口径切片足够拍板。本轮必须写 `【索取】无`。禁止再要总体均值，禁止把试探建模（弹性回归、完整优化输入）当成新索取。
>
> 把探索收成一张认知地图（约 100–150 行）：
> 1. 每节 3–6 条：交付物 / 结构 / 机制 / 口径歧义 / 约束关系 / 小问依赖 / 敏感性 / 方法族（每小问 1 主 + 2 对照，标不兼容）。
> 2. 互不兼容方向不能同时当主线。优先级：必做 / 应做 / 存疑。
> 3. **淘汰必须引用已回填数字或概览图**。
> 4. ≤8 个待人拍板点，各 2 个备选；能量化则给数量级差。
> 5. 单列 **可被后续求解推翻的清单**：方法或假设 / 何种脚本输出或敏感性会推翻它 / 现在为什么还留着。主持方在方法+代码跑完后会拿执行结果回看这张表，现在不算。
> 6. 论文若只保留 5–8 个探索点，哪些必须写。
> 7. 结尾固定：`【索取】无` ；`地图已可进入主持方 diff / 清点`。
>
> 通识可检索。禁止检索本题题解/优秀论文/评分标准。不要开始写求解代码。
