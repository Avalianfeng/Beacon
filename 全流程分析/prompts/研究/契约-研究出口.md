# 契约 · 研究会话出口（软）

> 学-21 / 学-39 · 出口是**收束时的外显记忆**，不是任务驱动清单。  
> 硬门禁只有：信息边界、成本预算、边际停止（见 [定稿 00](../../全流程定稿/00-正式闭环.md) §6、[10](../../全流程定稿/10-研究会话.md)）。  
> 脚手架：`python scripts/scaffold_research.py --problem problems/<题>`

## 研究过程中持续

| 产物 | 要求 |
|---|---|
| `_研究日志.md`（题根） | 重要认知变化必记；含推翻拍板/假设的六要素；**工作假设带来源**（`本地` / `外部-Vn` / `Diff拍板`） |
| `研究/_数据账.md` | 新表即登记：表ID · 路径 · 哪问 · 口径 · `_entry`/inject/仅人读 |

## 收束时至少留下

| 产物 | 要求 |
|---|---|
| `解题说明.md` | Q1–Qn 有交代；写实际方向与验证，非论文体 |
| `经验与坑.md` | 可复用失败与口径坑 |
| `exploration.md` | **人读**收束稿；与 brief 草稿同期；非对撞地图 |
| `brief草稿.md` | **最后**生成；章节覆盖 direction / data_notes / red_lines / formula_notes / figure_plan / background_knowledge / required_discussions |
| `研究/_数据账.md` | 收束冻结；插座作者据此写 `_entry`/inject |
| 脚本/表/图 | 关键数字可回溯路径 |

草稿自检（非正式）：`python scripts/check_brief_draft.py --problem …`  
正式过闸在 11：`math-agent brief check`。

## 收束后顺序（钉死）

```text
六件 + 数据账 → 11 brief.json →（12 预检）→ 13 交接 → 14 plan/登记
```

**禁止**收束后直接 `plan build`（跳过 brief）。

## 明确不是目标

- 正式 `paper.md` / PDF  
- 「四问文件模板填满」  
- 假装已跑通 Beacon `brief check`（那是 11）  
- 研究脚本与 `_entry` 同构

## 可被推翻

研究外显中的方向判断，应能指出：何种计算/回测会削弱或废弃该方向（可继承 Diff「可被推翻」并更新）；来源标签保留到日志。
