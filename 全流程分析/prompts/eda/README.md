# prompts/eda · 用法说明

本夹服务定稿 **[02-EDA画像](../../全流程定稿/02-EDA画像.md)**：把「扫附件出几张默认图」升级为**特征导向、看图迭代**的高自主循环。

产品方向仍在定稿 00/02。本夹只放可复用派发与出口契约。

## 谁用、何时

| 文件 | 谁 | 何时 |
|---|---|---|
| [说明-自主出图循环.md](说明-自主出图循环.md) | 主会话（必读） | 开 S1 前；决定自干还是派子任务 |
| [契约-图说出口.md](契约-图说出口.md) | 出图者 | 写 `eda/图说.md` 前 |
| [模板-派发.md](模板-派发.md) | 主会话派**一个**干净上下文子 agent（可选） | 附件多/表结构怪、主会话不想占上下文时 |
| [说明-怎么填本题派发.md](说明-怎么填本题派发.md) | 主会话 | 落到 `problems/<题>/_派发/eda.md` |

## 最短路径

1. 主会话读定稿 02 + 本夹「说明-自主出图循环」
2. 小表可主会话自干；大/怪表则填 `_派发/eda.md` 派子 agent
3. 交付：`eda/*.png` + `eda/图说.md` + `data_profile.md`（+ 可选脚本/JSON）
4. 主会话**真看图**抽查；不够则按图说「已知不足」重派或自改——**不要人没看图就进对撞**

## 与相邻夹的边界

| 夹 | 关系 |
|---|---|
| `外部/说明-怎么写读图任务.md` | 外发时把图说压缩成「图 / 画了什么 / 请回答」；不替代图说 |
| `本地/` | 本地探索**消费** EDA；不负责本站出图 |
| `研究/` | 研究图是求解证据；EDA 图是共享视觉底座，勿混 |
