# 模板 · 派发 · EDA 自主出图

真跑前按 `说明-怎么填本题派发.md` 填路径，落到 `problems/<题>/_派发/eda.md`。  
**一个**子 agent；可多轮改图，但交付落在同一题目录。

---

**工作区（可写）**：`<题根>/eda/` 与 `<题根>/data_profile.md`  
**只读**：`<题根>/problem.md`、`problem.json`、`source/`（勿改附件原件）

**禁止**：联网搜本题题解；读其他题目；读 `认知地图集/`；写 brief；写求解代码当正式解；把探索结论写进画像。

**必读（若仓内可达）**：

- `全流程分析/全流程定稿/02-EDA画像.md`
- `全流程分析/prompts/eda/说明-自主出图循环.md`
- `全流程分析/prompts/eda/契约-图说出口.md`

**目标**：让人（和后续外部/本地探索）**看见**本题数据的关键特征。

按自主出图循环工作：

1. 根据题面与附件，列出特征候选（优先级）
2. 选图型并出图（**张数不限**；特征优先，不为「每附件一张」凑数）
3. **打开自己生成的 PNG 看**：读得出假设特征吗？有误导吗？
4. 据此改策略、重绘；至少完成「首绘 + 看图改」两圈
5. 写 `eda/图说.md`（契约结构）+ 更新 `data_profile.md`

空模板/提交表：画结构几何，不要画假分布。  
列缺失：在图说与 profile 点名缺口。

**交付物**：

1. `<题根>/eda/*.png`（最终采用的图）
2. `<题根>/eda/图说.md`
3. `<题根>/data_profile.md`
4. 可复现脚本（如 `eda/_make_overview.py`）与可选 `_profile_stats.json`

只用简体中文。结束后在图说 §4 写一句：这些图够回答什么、不够回答什么。
