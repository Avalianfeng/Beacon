# 说明 · 自主出图循环

> 对应定稿 [02-EDA画像](../../全流程定稿/02-EDA画像.md)。  
> 目标：让人和外部模型**看见**数据特征；不是交装饰图，也不是提前解题。

## 核心原则

1. **特征优先**：先问「必须被看见的是什么」，再问「用什么图型」。
2. **张数不限**：「每附件一图」只是历史打包习惯，**不是**硬约束。一个附件可以多张；一张图可以跨附件对照；没有分布就不要硬画分布。
3. **看图迭代**：出图者必须打开自己的 PNG，用视觉特征检验假设；读不出就改图型/拆图/补图。
4. **克制**：图与图说只陈述结构/量级/对齐/异常/缺口；不写「应该用线性规划」「最优是…」。
5. **图说一等**：没有 `eda/图说.md` 等于本站未完成。

## 循环（必须走完至少两圈：首绘 + 看图改）

```text
题面气质 + 附件结构
    → 特征候选清单（带优先级）
    → 图型提案（特征 ↔ 图；可一对多）
    → 脚本出图
    → 真看 PNG：读得出？误导？缺块？
    → 调整策略（改/拆/补/删）
    → 更新图说 + data_profile
```

### 特征候选从哪来（提示，非清单义务）

| 题/数据常有的特征 | 常见有效图型 |
|---|---|
| 类别构成、资源占比 | 柱/条/堆叠；避免无意义饼图堆饰 |
| 同组内离散、长尾 | 直方图、箱线、点图 |
| 两数值量级与共变（不断言因果） | 散点（可 log）；加密度时再议 |
| 时间/季次/阶段 | 折线、分面、阶段色带 |
| 对齐/覆盖缺口 | 集合对照、缺失热力、结构示意 |
| 空模板 / 提交几何 | **结构示意图**，禁止假分布 |
| 列不存在（如销量） | 在图说与 profile **点名缺口**；不要用别的量冒充 |

### 「看图」时问自己

- 闭上 profile，只看这张图，能说出哪条特征？
- 会不会让人以为「已经有解 / 已经有销量 / 已经最优」？
- 最危险的误解是什么？要不要改标题或拆图消除？
- 外发拼一张是否会糊掉关键细节？该留单图细读吗？

## 角色

| 角色 | 做什么 |
|---|---|
| 主会话 | 默认可自干 S1；抽查图说；人闸前不进对撞 |
| 出图子 agent（可选） | 按 `模板-派发.md` 封闭在题目录；交付图+图说+profile |
| 人 | 说「够用」或点名补图 |

## 禁止

- 为凑「每附件一张」而复制同质柱图
- 把探索结论画进 EDA（相关热力当「已证明可替代」等）
- 只交脚本不交 PNG / 只交 PNG 不交图说
- 未看自己的图就声称 S1 完成
