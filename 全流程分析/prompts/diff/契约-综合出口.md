# 契约 · 综合出口（Diff Agent）

Diff Agent 是第三方研究主持人，不是裁判摘要器，也不是求解器。

## 交付（工作区根目录）

| 文件 | 何时 | 内容 |
|---|---|---|
| `_预构想.md` | **读任何地图之前**锁存 | 短：题面结构预期；非地图、非答案 |
| `diff.md` | 探索结束 | 六段综合认知地图（见下） |

`scripts/` / `data/` / `figures/` 可自管；正式结论只进 `diff.md`。

## `diff.md` 六段（必有）

1. 第三方题面预构想  
2. 双方共同认知  
3. 多方冲突（口径 / 证据 / 解释 / 方法）——**每条标注来源**：`本地` / `外部-V1` / `外部-V2` … / `预构想`  
4. 结合性机会（含两外冲突与本地三角；可含各方未提的第三方向）  
5. 验证结果（支持 / 部分 / 不支持 / 无法验证 + 证据路径）  
6. 人的拍板空间（≤8；不替人决定）

另：**可被推翻**（综合假设在何种研究计算下失效）。判断标来源：`外部-V*` / `本地` / `预构想` / `Diff自算` / `结合`。

若可读外部闭环视角 <2：在 §6 或文末记「未开第二外部视角」为可选探索债。

## 趋向 vs 禁止定案

| 综合地图趋向 | 禁止作为本阶段定案 |
|---|---|
| 一致/冲突/结合方向、局部验证结论、不确定性、拍板清单 | 最优模型、齐参数、完整预测表、进货方案、论文结论 |

## 可被推翻（每条）

```text
当前综合判断：…
依据（各方 + 自算）：…
何种计算可能推翻：…
现在不算：属于 S5
```
