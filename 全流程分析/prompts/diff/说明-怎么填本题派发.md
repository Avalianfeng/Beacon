# 说明 · 怎么填本题 Diff 派发

从 `模板-派发.md` 填路径，落到：

`problems/<题>/_派发/diff.md`

| 占位 | 填什么 |
|---|---|
| `<题根>` | 如 `E:\git_clone\Beacon\problems\cumcm23-c` |
| `<diff工作区>` | 如 `…\认知地图集\diff` |
| `<外部地图路径>` | 如 `…\外部\认知地图-GPT-….md` |
| `<本地地图路径>` | 现行版，如 `…\本地\V2\认知地图-本地.md` |

与本题 `diff/_预算.md` 一致。

**真跑**：人新开干净对话 → 复制本题 `派发.md` 的「可粘贴正文」→ 贴第一条消息 → 人在该对话交互。  
主会话**不** Task 代派；结束后主会话/人抽查 `_预构想.md` + `diff.md`。

**不要**写进派发：索取编号清单、诱导阅读顺序、主持人偏好结论、「谁对谁错」口吻。
