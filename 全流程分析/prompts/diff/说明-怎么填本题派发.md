# 说明 · 怎么填本题 Diff 派发

从 `模板-派发.md` 填路径，落到：

`problems/<题>/_派发/diff.md`

| 占位 | 填什么 |
|---|---|
| `<题根>` | 如 `E:\git_clone\Beacon\problems\cumcm24-c` |
| `<diff工作区>` | 如 `…\认知地图集\diff` |
| `<本地地图路径>` | 现行版，如 `…\本地\V1\认知地图-本地.md` |
| `<外部V1地图>` … | 每个已闭环视角：`…\外部\V1\地图\认知地图.md` 等；以 `外部/README.md` 可对撞列表为准 |

多视角说明：`prompts/外部/说明-多视角版本.md`。  
旧题若仍为扁平 `外部/地图/认知地图-….md`，把该文件当作唯一外部 V 填入即可，并在 diff 备注「历史单视角」。

与本题 `diff/_预算.md` 一致。

**真跑**：人新开干净对话 → 复制本题 `派发.md` 的「可粘贴正文」→ 贴第一条消息 → 人在该对话交互。  
主会话**不** Task 代派；结束后抽查 `_预构想.md` + `diff.md`（冲突段应有来源标注）。

**不要**写进派发：索取编号清单、诱导阅读顺序、主持人偏好结论、「谁对谁错」口吻；**不要**只给「主持合成外图」路径而藏起各 V 原图。
