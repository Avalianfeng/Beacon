# prompts · 用法说明

可复用模板与「下次怎么写」说明放这里。**题目目录 `_派发/` 放已填路径粘贴件**；通用正文在本夹。

产品方向协议已并入定稿 00 + 03–11。本夹只放可复用派发。  
**做题顺序**：`全流程分析/全流程定稿/`。

## 谁用、何时

| 目录 | 谁 | 何时 |
|---|---|---|
| `eda/` | 主会话自干，或派**一个**出图子 agent | S1：特征导向出图 + 图说；看图迭代（张数不限） |
| `外部/` | 人跑外部视角（可多 `V*`）+ 主持拼包 | S2：开放探索 → 索取 → 0.5-闭环；**读图从图说压缩**；**多视角见 `说明-多视角版本.md`** |
| `本地/` | 主持派**一个**干净上下文子 agent | S2a 一次长探索 → 两份视图；可读 `eda/图说.md` 不当结论 |
| `diff/` | **人**新开干净对话粘贴派发 | Diff：预构想 → 本地+全部已闭环外部 V* → 综合（学-17/36） |
| `研究/` | **人**在 Diff 对话**续跑**或新开粘贴 | 长研究会话（学-21）；brief 最后压缩 |
| `清点/` | 主持起草 + 人改 | **diff 之后**；产本地/diff 时禁读 |
| `登记/` | 研究者/接洽会话 + 主会话登记 | 第四幕：写 `_entry` / inject 前先读契约；骨架照抄模板 |

## 主持怎么用（最短路径）

0. **S1 EDA**：读 `eda/说明-自主出图循环.md`；交付含 `eda/图说.md`；**人看图**后再对撞  
1. **写外发事实包**：从图说压缩读图表 → `source/方向生产-提示词包.md`  
2. **登记并开跑外部 V1**：脚手架 `scripts/scaffold_external_maps.py`；契约见多视角 + 索取目录；pack 用 `--resolve-shared`  
3. **该 V 第 2 轮 A 后 0.5-闭环** → `V1/地图/`；更新 `外部/README`  
4. **探索空间**：需要时再 scaffold V2；Diff 前尽量 ≥2 外部闭环视角  
5. **本地**：V1 开跑一轮后粘贴 `_派发/本地.md`（可读 `_共享/切片`；禁读各 V 档案）
6. **Diff**：粘贴 `_派发/diff.md`；读本地 + 全部已闭环外部 V*  
7. **研究 / brief**：同前（学-21）

## 新题要临时写什么

- `eda/说明-怎么填本题派发.md` → `_派发/eda.md`（可选）
- `外部/说明-怎么写事实包.md` / `说明-怎么写读图任务.md` → `source/方向生产-提示词包.md`
- `外部/说明-多视角版本.md` + `说明-索取目录契约.md` → `scaffold_external_maps.py` 建 `外部/{_共享,V1}/`（V2 按需）
- `本地/说明-怎么填本题派发.md` → `_派发/本地.md`
- `diff/说明-怎么填本题派发.md`（填齐各 V 地图路径）
- `研究/说明-怎么填本题派发.md`
- `登记/`（通用）
