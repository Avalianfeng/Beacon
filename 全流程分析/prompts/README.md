# prompts · 用法说明

可复用模板与「下次怎么写」说明放这里。**题目目录 `_派发/` 放已填路径粘贴件**；通用正文在本夹。

产品方向协议已并入定稿 00 + 03–11。本夹只放可复用派发。  
**做题顺序**：`全流程分析/全流程定稿/`。

## 谁用、何时

| 目录 | 谁 | 何时 |
|---|---|---|
| `外部/` | 人跑第二家 + 主持拼包 | S2 开放探索 → 索取 → 0.5-闭环 |
| `本地/` | 主持派**一个**干净上下文子 agent | S2a 一次长探索 → 两份视图 |
| `diff/` | **人**新开干净对话粘贴派发 | Diff 状态：预构想 → 双图 → 综合验证（学-17） |
| `研究/` | **人**在 Diff 对话**续跑**或新开粘贴 | 长研究会话（学-21）；brief 最后压缩 |
| `清点/` | 主持起草 + 人改 | **diff 之后**；产本地/diff 时禁读 |
| `登记/` | 研究者/接洽会话 + 主会话登记 | 第四幕：写 `_entry` / inject 前先读契约；骨架照抄模板 |

## 主持怎么用（最短路径）

1. **外部第 1 轮**：拼图 + 复制 `外部/模板-提示词0.md` + 粘本题事实包  
2. **索取回填后**：按 `外部/协议-索取.md`；第 2 轮 = 最后一次证据补全  
3. **本地（学-16）**：粘贴本题 `_派发/本地.md`  
4. **Diff（学-17）**：人新开对话，粘贴 `_派发/diff.md`；主会话不代派  
5. **拍板/清点草稿后 · 研究（学-21）**：优先**同一 Diff 对话**粘贴 `_派发/研究.md`；见 `研究/说明-从Diff续跑.md`  
6. 研究成熟后：研究者交 `brief草稿` → 主会话收口 brief.json

## 新题要临时写什么

- `外部/说明-怎么写事实包.md` / `说明-怎么写读图任务.md`
- `本地/说明-怎么填本题派发.md`
- `diff/说明-怎么填本题派发.md`
- `研究/说明-怎么填本题派发.md`
- `登记/`（通用，不用临时写）：契约-代码插座.md + 模板-reference_入口.py + 模板-sensitivity.py
