# 学-23 · Diff 性质分化与「竞赛闭环」补位计划

> 触发：cumcm23-c 收束复盘（吴萌式「剥时间→价量→随机优化」 vs 本流程「识别诚实否证」）。

## 0. 核心是什么（一句话）

**把「数据识别得诚实」做成了目标函数，用否证习惯执行成「主线不做」；缺的是与识别正交的竞赛建模闭环——题面每个祈使动词必须有可计算出口（允许脏工作模型 + 讨论承认识别弱），不允许「不够干净所以定价不是决策变量」。**

不是 EDA 不够，也不是单 agent 不够严。是 **识别轴过强、决策轴过弱**；brief 过早把否证结果锁成红线后，S6–S7 critic 只能写清楚，不能补模型。

## 2. 对你三个战略问题的回答

### 2.1 是否过分依赖决定性 brief？

**是，但病不在「有 brief」，而在 brief 只压缩了识别主线。**  
更可靠的形状应是：

```text
并行尝试（≥2 条可计算出口）
  → 按「建模习惯/题面动词闭环/识别诚实」多轴打分
  → brief 压缩：主线 + 对照栏（都有数）+ 取舍理由
  → Beacon 忠实执行主线，讨论强制写对照
```

学-20/21「brief 后置」仍对；要改的是 **后置之前必须有分叉账本**，不是后置一个更干净的单点 brief。

### 2.2 论文主动记两个方向、有取舍、多个结论/数据——犯规吗？

**国赛常态是允许且加分的「主 + 对照/敏感性」**，不是犯规：

| 写法 | 是否规范 |
|---|---|
| 主方案一套表 + 对照方案一套表 + 明确取舍 | ✅ 常见高分结构 |
| 两套并列「都是最终答案」无取舍 | ⚠️ 评阅难打分；易扣「无结论」 |
| 只写「也考虑过弹性/报童」无表无数 | ❌ 本题已中枪（A+B 口头） |

建议产品默认：**一主一对照（或主+敏感性簇）**；「多结论」= 多套已算结果进附录/对照节，正文有唯一推荐方案。与学-10「最终说明尝试但不用」对齐。

### 2.3 缺建模思考；补满分论文怎么吸收？

**禁止**：对本题搜优秀论文/评分细则当答案键（现行硬禁）。  
**允许的吸收**（做成「体裁素养」库，与本题隔离）：

| 消化动作 | 产出 | 用途 |
|---|---|---|
| 剥「论文语法骨架」 | 卡片：题面动词→默认出口模板（分解/弹性工作型/报童/MIP…） | Diff 预构想检查表 |
| 剥「取舍话术」 | 如何写主对照、如何承认识别脏仍优化 | `required_discussions` 模板 |
| 剥「图表义务」 | 评阅人期待看见的表类型 | figure_plan 对照栏 |
| 反例卡 | 哪些「科学正确」会杀掉竞赛闭环 | 研究停止条件警示 |

落地形态建议：`全流程分析/prompts/建模体裁/` 或中枢 knowledge——**按题型族**（易腐定价、排程、评价…），不按题号。消化时只问：这条语法是否让祈使句可计算，不问「本题标准答案是什么」。

## 3. Diff 性质分化（计划核心）

现行 Diff 六段把多种性质混在「冲突 / 结合 / 可推翻」里。建议 **显式分轨**（仍一个会话、一份 `diff.md`，但段落/标签强制分流）：

### 轨 Ι · 识别轨（Identification）

- 时间混杂、窗口翻转、行级相关≠弹性、损耗口径冲突…  
- 出口允许：**强否证**（禁止把否证对象写进主公式）  
- 本题已做够；勿再加 hop 加强本轨。

### 轨 Δ · 决策轨（Decision / 题面动词闭环）**【新增硬检查】**

对题面每个交付动词建一行：

| 动词 | 可计算出口（工作模型可脏） | 若暂不做 |
|---|---|---|
| 分析关系 | 分布/相关/分解 | 不允许空 |
| 补货 | q=… | 不允许「只讨论」 |
| 定价 | **P 或 m 为决策变量的通道**（可对照） | 不可仅「P50 复述」除非书面放弃并进讨论预算 |
| 收益最大 | 目标函数对决策变量可求（或随机优化） | 不可用「无上界会计」单独封死——须给有界目标 + 决策变量 |
| 27–33 | 组合/筛选可算 | 可主硬池，但对照须有守恒口径 |

规则：**识别否证 ≠ 决策出口取消**。否证的是「用行级相关当弹性主公式」；不是「禁止任何 Q(m) 工作曲线」。

### 轨 Τ · 模板轨（Genre templates）

预构想阶段列出竞赛默认模板候选（报童、分解+回归、随机规划…），标注：

- 数据能否识别满参  
- **即使不满参，是否仍作工作分布/对照**  

本题：报童在预构想出现 → 拍板 8 抹掉；分化后应进「模板轨：对照必跑或书面放弃」。

### 轨 Υ · 可推翻执行账（Falsification ledger）**【研究站硬门】**

每条可推翻必须三态之一，禁止第四态：

| 态 | 含义 |
|---|---|
| 已跑 | 有脚本/表路径 |
| 未跑·预算外 | 书面原因 + 不影响主线声称 |
| 未跑·必须补 | **挡研究收束** |
| ~~已否证（未跑）~~ | **禁止** |

本题缺口几乎等于：固定篮子去季节弹性、报童工作分布 → 预构想有、S5 未跑、却进《经验与坑》。

## 5. 并行尝试与打分（产品形态草案）

不必上完整「多 brief」。最小可行：

```text
研究/
  fork-识别诚实/     → 现 cumcm23-c 主线
  fork-竞赛闭环/     → 剥时间残差 Q(m) + 工作报童 + 有界目标
打分卡（人+短提示）:
  题面动词覆盖 | 识别诚实 | 可复现 | 评阅语法完整度
brief 只宣布：主=… 对照=… 取舍=…
```

正赛「不计成本」时放大 fork 数（学-10）；探索性真跑至少 **1 主 + 1 对照**。
