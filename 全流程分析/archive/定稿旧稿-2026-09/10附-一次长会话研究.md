# 10附 · 一次长会话研究（原则详录）

> 定稿附属 · 学-21 · 2026-09-04  
> 操作面仍读 [10-s5-求解推进.md](10-s5-求解推进.md)；本文件保留决策细节，避免日后被短派发冲淡。

## 1. 改什么

| 旧 | 新 |
|---|---|
| Diff Agent → 求解 Agent 两个角色硬切 | **同一研究者**连续工作 |
| 核心目的 = 交齐日志/说明/brief草稿 | 核心目的 = **把题研究明白**；产物是副产品 |
| 拍板 = 必须遵守的锁 | 拍板 = **当前工作假设**；可证伪、须记账 |
| 工作区 = `求解/` 沙箱 + 必读清单 | 工作区 = **整题目录**；锁信息禁区，不锁发现路径 |
| 固定 Q1→Q4 顺序与停止清单 | 无机械顺序；停止看边际收益 |
| brief 在 Diff/清点后驱动求解 | **研究 → 结果 → 经验 → 再压 brief** |

## 2. 为什么 Diff 会话应直接续跑

Diff 会话已有内部状态：题面 → 预构想 → 外部 → 本地 → 冲突/互补 → 综合方向。  
从此进入真实数据与模型，比另开「什么都不知道的求解 Agent」更接近连续研究。

续跑时明确切换的不是角色名，而是目标：

- 从「比较已有认知」  
- 到「验证并推进自己的认知」

身份始终只有一个：**本题研究者**。

## 3. 研究环（而非任务清单）

```text
研究这道题
  → 理解机制 / 验证数据 / 尝试方案
  → 发现问题 → 修改理解 → 再实验
  → 方向变稳 → 真正跑到结果 → 留下经验
  → 最后才压成 brief
```

每一步问：是否显著增加认识，或显著提高当前方向可信度？  
优先：区分候选、否证假设、闭合关键口径、形成可复用结果。  
跳过：低价值重复统计、为填表而填表。

## 4. 三个硬控制（仅此）

1. **信息边界**：禁他题、禁联网题解/优秀论文/比赛答案；本题目录内可自行发现与使用。  
2. **成本预算**：时间 / token / 子 Agent / 磁盘——不是思考轮数。  
3. **边际停止**：认识已够稳，或继续探索不值得。

不规定：必须几轮、必须开子 Agent、必须按问序、必须先写 brief。

## 5. 子 Agent 何时值得

- **独立验证**：主结论已有，要另一视角只验数据  
- **分叉探索**：两方向并行，避免一条污染另一条  
- **机械工作**：大批整理、表格、代码检查  

子 Agent = 研究工具，不是第二研究者流水线。

## 6. 研究账本

题根 `_研究日志.md`：假设 → 实验 → 结果 → 认识变化 → 下一步。  
尤其记：关键发现/失败、被推翻假设、口径变化、模型淘汰、对 Beacon 有影响的经验。

## 8. 总图（学-21）

```text
新题 → 外部地图 × 本地地图
         ↓
   第三方研究者（Diff 状态）
         ↓
   长时间自主研究（续同一会话）
         ↓
   「做明白了」→ 研究经验 + brief 草稿
         ↓
   主会话 → brief.json → Beacon 论文链
```
