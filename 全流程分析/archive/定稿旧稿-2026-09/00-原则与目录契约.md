# 00 · 原则与目录契约

> 定稿 · 重写 · 学-13～22  
> 旧流程卡 → `archive/新题真跑草稿-2026-09/`。

## 角色

| 谁 | 做什么 |
|---|---|
| 人 | 跑第二家、开 Diff/研究会话、拍板、审清点/brief、评论文 |
| 主会话 | CLI、拼包、记盘、抽查、起草清点/收口 brief；**不**代写 Diff、不代评 |
| 本地 Agent | 一次长探索 → 两视图（证据卡+认知地图） |
| **本题研究者** | Diff 状态 →（同一会话）长研究 → 日志/说明/`brief草稿`（学-21） |
| 外部第二家 | 知识/方法探索 → 地图（经索取闭环） |

## 锁三件事（各探索/研究站通用）

1. **出口/收束契约**：阶段交付类型明确（地图 / diff / 研究外显 / brief），不是「禁止思考」  
2. **信息边界**：按站禁读；研究站锁他题与题解，不锁本题目录内发现路径  
3. **成本预算**：时间/token/子 Agent；不设「思考轮数」「至少算 N 次」

## 题目录契约（cumcm23-c · 学-22）

```text
problems/<题>/
  problem.md|json  data_profile.md   ← CLI/stage 留题根
  exploration.md                     ← 收束时人读产物（配合 brief；非对撞地图）
  本地资产清单.md  目录说明.md
  _派发/{本地,diff,研究}.md          ← 全部派发集中于此
  eda/  source/（含方向生产填充件）
  认知地图集/
    外部/{地图,轮次,外发归档,索取}/
    本地/Vn/   diff/   清点/
  （研究外显，题根）_研究日志.md  解题说明.md  经验与坑.md  brief草稿.md
```

已废止：题根 `索取/`、`对撞外部/`、`求解/`、题根 `清点/`、散落 `派发.md`。  
第二家操作指针：`认知地图集/外部/轮次/对撞-第二家提示词.md`。

## 硬禁止

- 先 brief 后对撞  
- 联网搜本题题解 / 优秀论文当依据  
- 薄 / 过早的 `exploration.md` 冒充本地认知地图（对撞地图在 `认知地图集/`；本文件是 brief 前人读收束）  
- 产本地时读外部地图 / 轮次 / 外发归档  
- 关键存在物只记对话框  
- 用 brief 草稿**驱动**尚未发生的研究（学-21）

## 标注约定（本定稿）

- `☑ 已落地` / `☐ 未做` / `◇ 暂留待吸收`  
- 文首「吸收自 / 旧版去向」说明来源，避免与 archive 双真

## 站序（清点之后）

清点(09) → **研究会话(10-s5)** → **brief定稿(11-s3)** → 预检(12-s4) → 证据登记(13-s5) → 论文(14-s6) → 评审(15-s7) → 验收(16-s8)；S9 可选。

brief 后置（学-20）；长会话续跑（学-21）；目录契约（学-22）。
