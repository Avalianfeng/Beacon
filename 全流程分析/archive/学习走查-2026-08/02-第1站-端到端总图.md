# 第 1 站：端到端总图

## 1.1 全链路

```
赛题源（Desktop，只读）─ 题目信息.md + 附件 + （赛后）官方细则
        │
        ▼
┌─ Beacon（E:\git_clone\Beacon）——生产 ─────────────────────────┐
│  S0 导入 → S1 数据探查 → S2 探索 → S3 brief → S4 预检 →         │
│  S5 求解验证 → S6 装配 → S7 评审 → S8 accept（S9 流水线可选）    │
└──────────────┬──────────────────────────────────────────────┘
               │ 交接：paper.md + evidence-package + 关键数字（数字唯一来源）
               ▼
┌─ D:\数学建模 工作面/<题目id>——后处理 ──────────────────────────┐
│  搭建 → 分节改稿 → 出图 → 支撑材料 → Word 交付 → 【赛后诊断】     │
└──────────────┬──────────────────────────────────────────────┘
               │ 回流：诊断 §6 规则 → Beacon T-xx 闸门/契约（登记 D-xx）
               ▼
        题目档案赛后段 → 下一题（教训卡片交叉引用、错误模式跨题复用）
```

## 1.2 内流程（Beacon 操作面 S0–S9）

| 阶段 | 产物 | 完成判据（机械门槛） |
|---|---|---|
| S0 导入 | `problem.md/json` + `source/`（哈希） | `problem show` 可读；questions 非空 |
| S1 数据探查 | `data_profile.md` + **每附件 ≥1 张概览图** | 概览图齐全（D-007 强制） |
| S2 探索 | `exploration.md` + `逐问清点.md` + **`领域知识.md`** | 领域知识卡存在（D-007） |
| S3 brief | `brief.json`（含口径分级/备选口径） | `brief check` [OK] |
| S4 预检 | `preflight.json` | `run --dry-run` 全过；blockers 空 |
| S5 求解验证 | 脚本 + `evidence-package.json` + `independent-review.json` | package 存在 **且** recertify `verdict=="pass"` |
| S6 装配 | `reference.json` + `runs/…/paper.md` + tables | 数字与 S5 锚点一致；可溯源 |
| S7 评审 | `review-report.json` | `review-check` 五闸门过 |
| S8 人审提交 | `acceptance.json`（approved=true） | `problem stage` 认 S8 |
| S9 流水线（可选） | runs 产物 | 不作主路径（D-005） |

关键设计：
- `problem stage` 按磁盘产物推演状态——「写好产物，下一棒读 stage」，无工作流引擎。
- b/c/d 强制产物（D-007）：b 数据先探（S1 画像+关键交付表锚点）、c 每附件 ≥1 张概览图、d S2 领域知识 → brief.background_knowledge。强制原因：数据没先探→对撞变方法名 PK；没图→探索凭想象；没领域知识→口径必错。

## 1.3 交接点与数字唯一来源

- 交接物：`paper.md` + `evidence-package.json` + `runs/` 产物 + `problems/<题号>/` 档案。
- 数字唯一来源：D 盘 `结果/关键数字.md`（= 可复跑代码实跑产物，附 文件:行号）——外流程一切数字以此为准。
- 原则：外流程不在 Beacon runs/ 里改论文当定稿；Beacon 不写评分细则、不做 Word 精排。

## 1.4 教训回流机制（五步）

沉淀（D盘 建模赛后诊断.md §6）→ 回流清单（"待注入 Beacon"节）→ 注入（T-xx 闸门/契约，登记 D-xx）→ 验收（新题真跑验证）→ 本地可修复项只回写本题。
实例：C 题五条 → check_l4_gates.py（G1–G4，D-006）。

## 1.5 题目档案生命周期

生产段（S0–S8 产物）+ 赛后段（赛后诊断.md / 教训卡片.md / calibration/）+ 知识段（领域知识.md）。
