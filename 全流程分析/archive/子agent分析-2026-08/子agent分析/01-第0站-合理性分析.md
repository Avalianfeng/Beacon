# 第 0 站合理性分析（worker · 2026-08-28）

## 一、内在逻辑是否自洽

- 总体自洽：方向层（开放、人主持）→ 执行层（机械可验证）→ 确定性层（哈希/闸门/溯源），每层工具与认识论地位匹配。
- **张力一**：S7 评审与自己的公理冲突——自审查对「方向未入认知空间」天然失明（教训 3）；S7 要么被限权为机械一致性检查，要么在承担它注定完不成的语义审查。
- **张力二**：重跑政策与哈希冻结、时间预算冲突——「改 brief 重跑」使已冻结哈希失效，需失败血缘保留管理（未言明）；比赛硬时限下重跑未必跑得完。
- **张力三**：探索职责边界模糊——验证途中涌现的探索性发现算「方向错（重跑）」还是「执行细节（继续）」无判定规则，这是重跑回路的分叉点。
- **张力四**：价值分布与平台身份错位——价值杠杆在 brief（平台外前置环节），Beacon 本体是转录+确定性，论文质量上限被平台外锁死。

## 二、最脆弱、最容易被绕过的环节

- **最脆弱：源头口径裁决**——mcm51-b 实锤根因，单点发生、不可机械化、全部闸门在它之后，且没有任何确定性证据能校验它（公理一自己承认）。
- **结构性绕过：冻结后的外部工作面（Word 化）**——最终提交物在最后一步脱离血缘链。
- **语义性绕过：空心证据**——闸门只查形式（有无代码、哈希一致），查不了含义；方向错误的论文可带完美溯源全绿通过。
- **社会性绕过：S8 人审变橡皮图章**——「哈希冻结、闸门全过、装配漂亮」恰构成人审放行的心理诱因，而人审是唯一能拦下方向错误的环节。
- **总通道：时间压力是全部机制的静默总开关**——「可选」步骤第一个被跳过、闸门放水、人审压缩，无对抗机制。

## 三、优化方向

- 机制：**brief 假设-证据对照表作闸门产物**——每条假设挂接题目原文证据或显式假设+可证伪测试；mcm51-b 式冲突会在此暴露，可机械检查。
- 机制：**断言溯源图**——终稿每个断言 → brief 条目 → 题目文本/假设，闸门双向覆盖（brief 未被覆盖=漏项；断言无出处=标红）；把溯源从「工件」升维到「主张」。
- 机制：**S4 与 S5 之间加廉价方向可行性探针**——最小规模试算，看方向能否产出合理数值，提前暴露「方向与数据冲突」。
- 分工：**S7 正名**——限定为「机械一致性+证据完备性」，语义方向审查移到前置或独立对抗角色；S8 人审改为对照 brief 的清单式核查。
- 激励：**赛后评估回灌前置**——brief 版本+得分构成方向生产数据集，把「方向命中率」变成可度量可优化指标（当前方向是最少数据的环节）。
- 机制：**重跑成本工程化**——数据探查结果方向无关可缓存；把「至少一次重跑」写进时间预算，否则 96 小时时限下重跑必被静默放弃。

## 四、公理充分性与隐含假设

- 公理一偷换：「评分无参考答案」→「口径无参考」；mcm51-b 恰证明裁判存在共享口径（否则何来冲突）——被否掉后系统失去唯一外部校准源。
- 公理一隐含：题目口径本身可确定（竞赛题常刻意开放，「官方意图」未必可判定）。
- 公理二隐含：两阶段可干净切分（验证途中常涌现探索性发现，唯一应对=昂贵的重跑）；探索没有「够了」的完成判据（验证有闸门，探索没有）。
- 公理三隐含：错误可被检测——但教训 3 明说最致命的空白小问连强模型自审都发现不了；风险全压给「人主持的前置质量」，而人是系统里最不可控的输入。
- 公理三隐含：口径裁决者拥有信息优势（联网/官方文本）；若无，裁决只是另一种 LLM 意见披着裁决外衣。
- **公理缺失**：三条公理全是方向导向——证据铁律未提升为公理、机械层无公理地位、时间公理缺失（硬时限是全部机制的隐含成本项）。
- **最深隐含：证伪主义认识论**——「确定性证据淘汰错误」隐含前提是错误可被数据/代码证伪，而 mcm51-b 的方向错误（语义口径冲突）提交前在数据上不可证伪——证伪主义恰在历史失败点上失效。

## 最值得注意的一点

**风险分布与控制分布错配**：最强的自动化机械（哈希/闸门/溯源）部署在历史上从未杀死它的环节（流程与证据）；真正的杀手——方向口径——只由最弱、最依赖人、最不可规模化的前置碰撞环节守护，且其补救回路（重跑）的前提（错误可检测）恰被自己的教训 3 否定。一句话：这套体系能完美证明「一篇错误的论文被正确地生产了出来」，却对「论文是否正确」没有任何证据能力——而它的主要投入恰恰花在前者。
