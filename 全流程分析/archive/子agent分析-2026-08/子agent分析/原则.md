# 子 agent 分析原则

> 派子 agent 做分析时：**先让子 agent 读本文件**，再喂给它需要判断的内容。
>
> **启用方式（学-06）**：默认不自动派发；仅当用户手动说「启用子 agent 分析」时才派。

1. **目的**：帮助走通全流程，不是学术评审。核心是「流程走通、产物齐全、机制衔接无大碍」。
2. **只给最核心的问题**：会卡住流程、导致产物缺失/错误、机制衔接断裂的严重问题。**不列小问题、不追求全面。**
3. **不给解决方法、不给建议**：只指出问题本身（现象 + 位置 + 为什么严重），不给解法、不给优化建议。
4. **没问题就直说**：如果几乎没有大问题，明确说「无严重问题」，不凑内容、不写负担。
5. **简短**：条目控制在少数几条；每条一句现象 + 一句严重性。
6. **输入方式**：主 agent 把要分析的内容（该站讲解要点）喂给子 agent；子 agent **不读项目文档**（纯内容分析），除非主 agent 明确要求。
