# 全流程可视化

依据 `全流程分析/全流程定稿/00-正式闭环.md`。每块一目录：`source.json` 为规格，`diagram.html` 为交付物。用浏览器打开 HTML。

| 目录 | 图类型 | 看什么 |
|---|---|---|
| [01-总览](01-总览/diagram.html) | workflow | 五幕一条主链 + critic 交回 |
| [02-第一幕-找方向](02-第一幕-找方向/diagram.html) | workflow | 导入 / EDA / 双边探索 / Diff 拍板 |
| [03-第二三幕-研究与brief](03-第二三幕-研究与brief/diagram.html) | workflow | 研究者实算 → brief 手柄（准备 ≠ 结束） |
| [04-第四五幕-Beacon闭环](04-第四五幕-Beacon闭环/diagram.html) | workflow | 预检 · 登记 · 图跑 · writer · accept |
| [05-角色](05-角色/diagram.html) | architecture | 人 / 主会话 / 两家探索 / 研究者 / Beacon |
| [06-图内节点](06-图内节点/diagram.html) | sequence | 图里还用哪些节点（coder_generate 默认关） |
| [07-失败交回](07-失败交回/diagram.html) | lifecycle | critic 停机 → 手改 → 再跑 → 人评 accept |

不要用 S0–S9 当另一套主路径。
