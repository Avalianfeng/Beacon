# 新题真跑 · 流程卡

> 对照操作面契约、总纲、docs/18、走查记录交叉梳出来的**现行交棒**。单份手册若与本卡冲突：命令名信契约，顺序信本卡（实操修正：先 EDA、对撞后再 brief）。
> 本轮是探索性真跑：允许中途停、返工、降级「最小可交」；不要求一次满分。

## 禁止

- 先 brief 后对撞（C 题赶工顺序，不用）。
- 联网搜本题参考答案 / 优秀论文 / 评分标准。
- 无 EDA 包的「方法名 PK」对撞。
- 改 brief 后在下游用生成文字圆口径（回 S3，从 S4/S5 重来）。
- **用薄探索草稿冒充本地对撞一方**（学-14：过薄则重产 `认知地图集/本地/认知地图-本地.md`）。
- **产本地地图时读外部材料**（提示词包、交棒、给第二家打包图、外部索取原文、外部认知地图）。
- 主持人对关键存在物只记在对话里、不落盘。



## 探索性约定

走不通就停在该站记缺口类型，换最小可交或等人；不假装命令存在，不顺手改 Beacon 机制（除非命令本身失败）。

### 学-14 / 学-15 / 学-16 本地地图与主持人记盘（2026-09-04）

**地位**：本地与外部地图对等。本地是完整研究能力的独立探索者；工作产品是认知地图，不是最终答案（学-15）。

**锁三件事**：出口（地图含可推翻）、信息边界（本题工作区封闭；不读外部地图/交棒/外发图/他题/题解）、成本（见 `_预算.md`）。**不**硬禁回头、实验、局部验证；**不**设「至少算 N 次」。

**一次长探索，两个视图（学-16）**：一个子 agent；`_证据卡.md` = 事实视图，`认知地图-本地.md` = 认知视图。不是 hop1→人审→hop2，也不是两个模型。核心 prompt 极短；不在 prompt 里罗列可读文件诱导路径。

**边界 / 存在物**：Agent 见短派发里的工作区根 + 禁出类别；主持记盘用该题 `本地资产清单.md`（不要整表贴进 Agent prompt）。

题目录物理结构见该题 `目录说明.md`。地图分 `认知地图集/外部/` 与 `本地/`，diff 另文件。

产法：`全流程分析/新题真跑-本地地图产法.md`。短派发模板：`全流程分析/prompts/本地/`。本题：`认知地图集/本地/派发.md`。

**主持人**：知存在、写清单与成本账、结束后一次抽查；失败则重派同一任务。外部材料一律进 `认知地图集/外部/`（地图 / 轮次 / 外发归档 / 索取）。

### 学-17 Diff = 第三方综合（2026-09-04）

**地位**：对撞的第三认知阶段——比较 + 综合 + 有限验证；**不是**主会话写对比表，也不是 S5。

**怎么跑**：**人新开干净对话**，粘贴本题 `认知地图集/diff/派发.md` 的「可粘贴正文」，在该对话里交互。主会话**不** Task/子 agent 代派。

**硬顺序**：题面 → 锁存 `_预构想.md` → 才读外部/本地地图（防锚定）。自管工作区 `认知地图集/diff/`（可 scripts/data/figures）。

**出口**：`diff.md` 六段（预构想摘要 / 共同 / 冲突四类 / 结合机会 / 验证结果 / 拍板≤8）+ 可推翻；判断标来源。可用代码验证结合方向，不可闭合成进货表/最优解。

**主会话**：准备粘贴稿、事后抽查；之后清点/brief。不自己写 diff。

产法：`全流程分析/新题真跑-diff产法.md`。模板：`全流程分析/prompts/diff/`。本题：`认知地图集/diff/派发.md`。

对撞中的【索取】分两层（**协议约束，不做成 Beacon 命令上限**）：


| 层      | 问的是什么                                        | S2 是否做                  | 正赛                                |
| ------ | -------------------------------------------- | ----------------------- | --------------------------------- |
| A 口径   | 看不见就会拍错板：集合定义、口径是否可忽略、双表是否同一量、窗口下降是构成还是掉 SKU | 做；建议 **最多 2 轮、每轮 ≤8 条**；**第 2 轮 = 最后一次证据补全**（不是第二次开放探索） | 同样封顶；封顶是防探索阶段被建模试探吃掉，不是省钱         |
| B 试探建模 | 同 SKU 弹性、完整优化输入、按他的模型把表跑一遍                   | **默认不做**；记「S5 待算」       | 时间充裕可在 S5 不计代价做；不要回写进 brief 当已证方向 |


贴回主会话的内容必须包括：**判断 / 地图更新 / 最容易漏掉的东西**，不能只贴【索取】块。主会话结合对方判断与本机证据决定：再算一轮 A，或直接发 **提示词 0.5-闭环**（禁止再索取）。B 条回「延后 S5」，不装成拒绝数据。

**S5 后回看**（不是 S2 的事）：方法选用 + 建模代码跑完后，拿执行结果对照对撞阶段列出的「何种计算会推翻该方法」。路线要改再改 brief/回 S5，不要在探索阶段用无限索取代替这次回看。

本机可留分文件。**对外只交打包件**：

```text
python scripts/pack_external_upload.py --dir problems/<题号>/认知地图集/外部/索取 --stem 给第二家-打包
```

得到 `给第二家-打包.md` + `给第二家-打包.png`。闭环轮把「你要了什么 / 我们给了什么 / 走到哪 / 提示词 0.5-闭环」写进交棒，再打进打包 md，第二家同一批文件就能出地图。过程记 `全流程分析/新题真跑-索取记录.md`。

首轮对撞四张概览图也可先拼成一张：

```text
python scripts/pack_external_upload.py --dir problems/<题号>/eda --glob-png "附件*.png" --stem 概览四合一 --md-skip
```

可复用提示词模板与用法：`全流程分析/prompts/README.md`。
