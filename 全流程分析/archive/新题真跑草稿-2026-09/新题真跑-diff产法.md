# 新题真跑 · Diff 产法（第三方综合）

> 地位：对撞的**第三认知阶段**。不是「比较两篇文章」，也不是 S5 解题。  
> 对应决策：**学-17**。前序：学-14/15/16（本地）、学-13（索取闭环）。

---

## 0. 一句话

**预构想 → 双图读取 → 结合性假设 → 有限验证 → 综合 diff。**

Diff 角色由人**新开干净对话**扮演（粘贴本题 `diff/派发.md` 可粘贴正文，人机交互推进）。  
主会话**不** Task/子 agent 代派；只准备派发稿、事后抽查，再进清点/brief。不自己写 diff。

---

## 1. 在整条链上的位置

```text
新题
 │
 ┌────────────┴────────────┐
 ↓                         ↓
外部独立探索                 本地独立探索
知识 / 方法 / 机制           数据 / 计算 / 反例
 ↓                         ↓
外部认知地图                本地认知地图
 └──────────┬──────────────┘
            ↓
    人新开对话 · Diff 角色（本产法）
      预构想 · 比较 · 综合 · 验证
            ↓
     综合认知地图 / diff.md
            ↓
      人 + 主会话：清点 / 决策 / brief
            ↓
           S5 → 回看可推翻契约
```

四层分工：

| 角色 | 认识机制 | 不做什么 |
|---|---|---|
| 外部 Agent | 未知世界 / 先验与方法 | 不读本题私有切片去「抄本地」 |
| 本地 Agent | 数据世界 / 证据与反例 | 不读外部地图 |
| **Diff 对话**（人新开） | **交叉空间**：比较 + 综合 + 局部验证 | **不闭合成竞赛解** |
| 主会话 | 准备粘贴稿、抽查、清点/brief、全流程状态 | 不代派 Diff；不手写 diff |

约束三者的仍是：**信息角色 + 资源预算 + 交付阶段**——不靠「禁思考 / 禁代码 / 禁回头」。

---

## 2. 为什么必须有「预构想」

若 Diff 一上来就读两张地图，极易变成：

> A 说 X，本地说 Y，我来二选一。

真正需要的第三视角是：

> **如果没有这两张地图，我自己先怎么看这道题？**

因此硬顺序：

```text
题面（+ 必要基础元信息）
      ↓
独立预构想 → 锁存 `_预构想.md`
      ↓
才允许读外部地图 + 本地地图
      ↓
冲突 / 结合方向 → 自主验证 → diff.md
```

`_预构想.md` 不是第三份认知地图，也不是答案。控制在**几百字到一两页**，只答：

- 这题核心矛盾是什么？
- Q1–Qn 各自可能要闭合什么？
- 哪些量之间最关键？
- 哪里最可能有信息缺口？
- 哪些机制我预期会出现、但尚未验证？

事后可用来检查：Diff 是在「自己坐标系里综合」，还是在「沿两张地图修辞」。

---

## 3. Diff 的三种合法动作

| 动作 | 含义 | 例 |
|---|---|---|
| **比较** | 外部说什么 / 本地说什么 / 与预构想差在哪 | 一致、冲突、遗漏、超出预期 |
| **综合** | 两边单独都不完整，组合后是否有第三解释 | 外部「时间结构」+ 本地「窗口相对基线下降」→「分品类混合基线」候选 |
| **验证** | 结合方向若为真，数据是否支持 | 跑同期 / 近90 / 365 / 组合对照；支持 / 部分 / 不支持 / 无法验证 |

文字差一句「一致」没有价值；**结合性洞察**才是本站核心。

---

## 4. 能力边界（内部自由，锁出口）

**可以**：读题与本题数据；读双方地图与本地证据卡；为结合方向写脚本、出图、局部面板/对照；推翻任一方；提出双方都没有的第三方向。

**不可以**（滑入 S5 的红线）：

- 定最优模型 / 估齐参数 / 出完整预测表或进货方案  
- 把局部验证包装成「本题已解」  
- 联网搜本题题解 / 优秀论文  

边界公式与学-15 同构：

> 可以用代码**验证认知**，不能把探索**闭合成竞赛解**。

相对前两方：Diff **更应积极算「组合问题」**（交叉空间是它的职责），但仍受预算与出口契约约束。

## 5. 工作区

```text
认知地图集/
  外部/     …外部地图
  本地/Vn/  …现行本地（含证据卡与自算资产）
  diff/     ← Diff 自管探索工作区
    README.md
    _预算.md
    派发.md
    _预构想.md      ← 读地图前锁存
    diff.md         ← 最终认知层交付（根目录）
    scripts/ data/ figures/   ← 自由实验，可留复现
```

临时计算进 `data/` / `figures/`，**不要**把中间表整段糊进 `diff.md`。

---

## 6. 出口：`diff.md` 六段

1. **第三方题面预构想**（可短引或摘要 `_预构想.md`）  
2. **双方共同认知**（两侧独立支持的）  
3. **双方冲突**（区分：口径 / 证据 / 解释 / 方法）  
4. **结合性机会**（外部 X + 本地 Y → 可能 Z；可含预构想未料到的）  
5. **验证结果**（哪些 Z 已跑：支持 / 部分 / 不支持 / 无法验证；附本工作区证据路径）  
6. **人的拍板空间**（≤8 个真正要人决定的问题；Diff **不替人拍板**）

另须保留：**可被推翻**——综合假设 Z 在何种 S5 计算下失效。每条判断标来源：`外部` / `本地` / `预构想` / `Diff自算` / `结合`。

---

## 7. 成本与停止

见本题 `认知地图集/diff/_预算.md`。停止条件：

- 结合方向的关键验证已有结论，或明确「无法在预算内验证」；且  
- `diff.md` 六段齐全、拍板清单 ≤8；或  
- 预算尽 / 人喊停。

剩余未验方向进拍板清单或可推翻，不硬凑「算够 N 次」。

---

## 8. 验收（主持一次抽查）

- `_预构想.md` 时间上是否在读地图之前（或文中自证顺序）  
- 有无偷读禁区（他题、联网题解、清点/brief 草稿、主持人判断）  
- `diff.md` 是否滑成求解定案  
- 结合方向是否有验证痕迹（或诚实写「未验」）  
- 假数字 / 明显事实错误  

失败：同一派发正文开新对话续修（或原对话带预算改），不拆成「只改某一段」。

---

## 9. 真跑顺序

1. 人确认本产法（学-17）。  
2. 主会话/人事先填好本题 `diff/派发.md` + `_预算.md`。  
3. **人**新开干净对话（Agent 模式），粘贴 `派发.md` 的「可粘贴正文」为第一条消息；在该对话交互。  
4. 该对话自管 `diff/`；根交付 `_预构想.md` + `diff.md`。  
5. 主会话抽查 → 人认可用 → 清点 / brief（用 `prompts/清点/`）。  
6. S5 后回看三层「可推翻」。

可选：diff 文末附 `V1×外部` / `V1×V2` 短注；**主对照永远是现行本地 × 外部**。
