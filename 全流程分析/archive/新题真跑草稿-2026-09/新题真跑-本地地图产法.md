# 新题真跑 · 本地认知地图设计

本题执行处：`problems/<题>/认知地图集/本地/`。  
可复用短派发：`全流程分析/prompts/本地/`。  
**真跑前先定本文件；真跑时粘贴本题短派发，不靠主持现场发挥。**

---

## 0. 一句话

**一次长探索，两个视图。**

一个本地 Agent、一个目标（建立认知地图）；探索过程中随手沉淀事实层，结束时压缩成认知层。两份文件是主持人的**观察窗口**，不是两阶段任务，更不是两个模型。

---

## 1. 在全流程里干什么

S2 要对撞，必须有两份独立地图。外部在 `认知地图集/外部/`。本地不能用薄 `exploration.md` 凑数。

**定位（学-15 + 学-16）**：本地是完整研究能力的独立探索者；工作产品是**认知地图**（含可推翻），不是最终答案。外部给先验/广度/机制；本地给证据空间与可计算实验；人做方向决策。

只锁三件事：

1. **出口**：交地图（含可推翻），不交最优模型+参数+进货表+论文定案  
2. **信息边界**：封闭在本题工作区；不读外部地图/交棒/对撞材料/他题/联网题解  
3. **成本**：子 agent 个数、墙钟、脚本调用有上限（`_预算.md`）

**不**锁：阅读顺序、实验次数、是否回头、是否局部建模。  
**不**用「至少算 N 次」驱动行为；用「关键判断缺证据就主动算」驱动。

本设计只覆盖本地地图怎么计划、怎么派、怎么验收。Diff / 清点 / brief 见 `新题真跑-diff产法.md` 与流程卡。

---

## 2. 已定原则（学-14 → 学-16）

| 点 | 内容 |
|---|---|
| 地位 | 本地与外部对等，都是对撞一方 |
| 过薄 | 首份探索草稿不当对撞输入 |
| 能力 | 内部自由：读、算、回头、质疑、局部验证 |
| 出口 | 压成认知地图；后续还有 diff→清点→brief→S5 |
| 独立 | 产本地时不看外部索要、交棒、外发图、外部地图 |
| 提示词 | **极短**；核心只说「要认知地图」；不列可读文件清单诱导路径 |
| 边界写法 | **探索工作区自管** + 题数据只读 + 禁出；不靠长「可读：A/B/C…」 |
| 工作区 | 版本目录（如 `本地/V2/`）= Agent 自管根：可建复杂代码/子目录/自用图；脚本不要求删；**交付物在该根目录** |
| 两份文件 | 事实证据卡 + 认知地图 = 同一探索的两个视图，**不是** hop1→人审→hop2 |
| 派发 | **一个**子 agent 一次跑完；问题则带预算重派同一任务，不拆「重做第一跳」 |
| 主持 | 知存在、写清单与成本账；不写本地正文；不靠对话记忆 |
| 机制 | 不为此加 Beacon 命令 |

污染两层仍要防：

1. **正文污染**：写地图的人读了外部地图或交棒。  
2. **议程污染**：切片顺着外部索取算的——数可用，**章节必须从题面小问长出来**。

主持会话已读过外部地图，因此**主持不写本地正文**。

## 3. 结构（取消「两跳工作流」）

```text
              一个本地 Agent
                     │
          目标：建立认知地图
                     │
     自主读 / 算 / 回溯 / 质疑
                     │
        ┌────────────┴────────────┐
        ↓                         ↓
   _证据卡.md              认知地图-本地.md
   （事实视图）              （认知视图）
        │                         │
        └────────────┬────────────┘
                     ↓
                  主持人抽查 → 可对撞则 diff
```

| 文件 | 是什么 | 不是什么 |
|---|---|---|
| `_证据卡.md` | 探索中沉淀的事实层：已确认事实、数字、来源、口径、异常、不确定、自算 vs 已有 | 不是「第一阶段必须交卷」；可随探索改写 |
| `认知地图-本地.md` | 探索结束时的压缩投影：问题空间、机制、候选、冲突、拍板、可推翻 | 不是第二阶段新任务；不是求解定案 |

Agent **从一开始**就按完整探索工作；不要进入「先把证据卡做完」的资料整理锁死模式。证据卡是过程记录，地图是终点压缩。

## 4. 角色

| 角色 | 做 | 不做 |
|---|---|---|
| 人 | 确认设计；批超预算；认可可否 diff；必要时要求重跑 | 不要求对话框贴表 |
| 主持 | 维护清单与 `_预算.md`；粘贴短派发；结束后抽查；记进度 | 不写地图正文；不把外部句子补进本地；不规定阅读顺序 |
| 本地子 agent（1 个） | 在封闭工作区内自主探索；交付两份视图 | 不读禁区；不交最终求解结果当答案 |

## 5. 目录

```text
认知地图集/
  外部/              产本地时禁读
  本地/
    README.md
    派发.md           本题短派发（可粘贴）
    _预算.md          成本账
    V1/               旧版归档（重跑时禁读；diff 可对照）
    V2/               **探索工作区**：Agent 自管；根上交两份视图；
                      其下可有 scripts/、figures/、中间表等（不要求清临时）
  diff/              Diff 自管工作区（学-17；非主持手写单文件）
    _预构想.md / diff.md / scripts|data|figures
  diff.md            （旧设想路径；现行交付在 diff/ 根）
本地资产清单.md        主持索引（存在物）；不是 Agent 必读目录
```

**探索工作区 ≠ 整题目录**：题根只作只读数据源；写入与实验沉淀落在现行版目录（如 `V2/`）。交付物必须在该版**根**上：`_证据卡.md`、`认知地图-本地.md`。

版本目录：第一次产出归档为 `V1/`，学-16 重跑写入 `V2/`，便于以后 diff 看多版。旧名 `派发-1-*.md` / `派发-2-*.md`：**废止**。

## 6. 信息边界（怎么写给 Agent）

**主写法**：本题根目录是封闭工作区；只在其中（及其中数据源）活动；禁止离开。

禁止类（说类别，不靠长「去读这些禁文件列表」当探索地图）：

- 其他题目目录  
- `认知地图集/外部/地图/`、`外部/轮次/`、`外部/外发归档/`  
  （`外部/索取/` 编号切片可读） 
- 写给第二家的交棒/打包/提示词填充议程  
- 主持人判断、索取记录里转述对方判断的段落  
- 联网搜本题题解  

**不要**在派发里罗列「先看 data_profile，再看 01–15…」。让 Agent 自己 `ls` / 发现。

主持侧的 `本地资产清单.md` 仍可记「仓里有什么」（记盘用）；**不要整表贴进 Agent prompt**。

## 7. 出口契约（两份视图要够主持消费）

### 7.1 事实证据卡

建议行：`主张 | 数 | 文件或自算 | 口径一句话 | 对哪一问有用`  
可附极短 `异常：` / `不确定：`。标明哪些是本轮自算、哪些来自已有产物。  
不要写成方法定案（「有季节性」可以；「所以用某某算法」放地图）。

### 7.2 认知地图

按**题面小问**长出来（不要按索取编号分章）。趋向：看见了什么、口径歧义、候选与互斥、方法族（族级）、证据、冲突、拍板点、**可被推翻契约**、论文必写探索点、引用抽查。

可被推翻（每条）：

```text
当前判断：…
依据：…
何种计算可能推翻：…
现在不算：属于 S5
```

硬禁止当定案：最终进货表、最优参数全集、把整链求解包装成答案。  
**可以**为判断方向做局部计算/局部模型；只要最终压进地图与可推翻。

详式见 `全流程分析/prompts/本地/契约-地图输出.md`（主持校对用；短派发已含要点则不必强令 Agent 先读长文）。

## 8. 成本与停止

每题 `认知地图集/本地/_预算.md`。默认量级：

- 本地探索子 agent：**1**（一次长跑）  
- 额外互评 critic：**0**  
- 墙钟 / Python·shell 粗上限（真跑前可改）  
- 停止：地图已够支撑 diff/brief，或预算尽，或人喊停  
- Agent 可自报「还想再跑」→ 人批或写入可推翻  

停止条件不是「想完了」，而是：**继续探索的边际价值低于成本**。

---

## 9. 验收（结束后一次抽查）

不再做「hop1 审完再 hop2」。Agent 交两份文件后，主持一次查：

- 禁区路径是否出现在工具轨迹 / 引用里  
- 证据卡随机抽数能否对上源文件或自报脚本  
- 地图是否按题面小问；有无可推翻；有无最终进货/最优参数定案  
- 有无真正认知增量（相对薄草稿），而非空壳模板  

失败 → **带预算重派同一短任务**（或人指定修哪一块），不是「重做第一跳」。

---

## 10. 真跑顺序

1. 人点头本设计（学-16）。  
2. 主持粘贴本题 `派发.md` → 一个干净上下文子 agent。  
3. Agent 自主探索，结束时留下 `_证据卡.md` + `认知地图-本地.md`。  
4. 主持一次抽查；人确认可对撞后进 **Diff（学-17）**，不主会话手写对比表。  

本题若已有学-15 两跳产物：可保留作对照；**学-16 生效后的标准跑法是单 agent 重跑**（人下令才重跑）。

---

## 11. 观察点（3～5 题后再改机制）

在相同预算下，自由探索 Agent 会不会自己形成有价值研究路径？若仍是「读已有 csv → 拼卡 → 写地图」，再分开判：

1. 短 prompt 是否仍不够诱导探索  
2. 工作区结构是否过度诱导整理行为（预煮切片太多）  
3. 模型在此任务上是否本身不主动研究  

不要急着加「至少算 N 次」或默认互评 critic。
